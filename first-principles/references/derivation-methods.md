# 推导方法：拆解结构、识别因果、反演思考

第 5–6 步（拆解与从头推导）的方法库。按需取用，不要全上。

## 目录

1. 结构拆解
2. 因果拆解
3. 反演思考
4. 类比与推导的区分
5. 二阶效应检查

## 1. 结构拆解

把问题拆到"再拆下去就是废话"为止。常用切法：

- **按功能切**：这个结果由哪几个独立功能块组成？（例：餐厅利润 = 客流 × 客单价 × 毛利率 − 固定成本）
- **按环节切**：这个过程从起点到终点有哪几个环节？瓶颈在哪一环？（例：求职 = 被看见 → 被筛选 → 面试 → 谈薪，提升哪一环的边际收益最大？）
- **按利益方切**：这件事涉及谁？每一方要什么、怕什么、能做什么？（商业问题尤其有效）
- **按时间切**：现在 / 近期 / 远期分别被什么决定？（不可逆决策尤其有效）

拆解质量自检：拆出的每一部分能否独立回答"它变化，结果怎么变"？拆不出答案的颗粒度就是白费。

## 2. 因果拆解

- **找驱动变量**：在所有变量里，哪 1–3 个真正驱动结果？（测试方法：把它固定，结果还变吗？）
- **区分相关与因果**：两个变量同向变化，常见三种解释——A 导致 B、B 导致 A、C 同时导致 A 和 B。没有机制解释的相关性，禁止直接当因果用。
- **画因果链**：把"做了 X → 得到 Y"中间省略的环节补全。补不出来的环节就是黑箱假设。（例："做品牌 → 销量好"中间隔着认知 → 信任 → 首选 → 购买，每一环都可能断。）
- **寻找反馈回路**：结果会不会反过来影响原因？（例：降价 → 销量涨 → 产能紧张 → 质量降 → 口碑坏 → 销量跌。）

## 3. 反演思考

想不通"怎么做对"时，反过来问：

- **反向目标**："怎样确保这件事彻底失败？" 列出来，逐条避免。比正向苦想更快暴露盲点。
- **反面前提**："如果这个前提是错的，我现在该怎么做？" 为关键假设各准备一条退路，退路的成本就是该假设的风险定价。
- **极端约束**："如果预算/时间砍掉 90%，我还会这么做吗？" 会 → 方案有真价值；不会 → 方案里掺着惯性。
- **时间反演**："三年后回看，今天什么会让我们后悔？" 不可逆决策必做。

## 4. 类比与推导的区分

类比推理（"像 X 一样做"）的问题不在快，在于**默认了前提相似**。类比可以帮你产生候选，但必须回答：

1. 那个成功案例的哪些约束和我的约束相同？
2. 哪些不同？不同的部分会不会改变结论？
3. 成功样本里有多少失败者没被看见？（幸存者偏差）

通过这三问的类比，等价于一条经过检验的推导，可以使用。通不过的类比，只能当灵感，不能当依据。

## 5. 二阶效应检查

对推荐路径至少问三层：

- **一阶**：做了 X，直接发生什么？（人人都会想到）
- **二阶**：因为一阶结果，什么会跟着变？（用户行为、竞争者反应、内部激励、成本结构）
- **三阶/系统效应**：二阶变化积累后，系统状态会不会反转？（例：效率工具 → 工作量增加 → 期待值上升 → 更忙）

二阶效应不是越多越好——快速模式下只检查最可能的 1 条二阶效应即可。深度模式对每个重大推论都做。
