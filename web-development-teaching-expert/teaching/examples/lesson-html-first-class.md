# 《网页设计与制作》教案 · 第1次课：初识网页——做出你的第一个网页

- 课时：2 学时（90 分钟）｜ 对应教材：第1章 HTML5基础 ｜ KP：KP1.1、KP1.3、KP1.4、KP1.5
- 依据文件：`chapters/ch01-html5-basics.md`（原文核对：教材第1章，full_text.txt 行162–1210）

## 一、这节课教什么
网页的工作原理（请求—响应）、HTML 标记符与属性语法、网页最小骨架，以及"编写—保存—双击打开—修改—再保存"的完整实操闭环。

## 二、为什么要学
告诉学生："从今天起你访问的每一个网站，底层都是你今天要学会写的东西。90 分钟后，你的第一个网页就能在浏览器里打开。"——用学生常逛的网站右键"查看网页源代码"建立直观连接。

## 三、学生学完能够做什么（可测量）
1. 能口述浏览器访问网页的"请求—响应"过程（理解）；
2. 能用记事本独立写出含 `html/head/title/meta charset/body/h1/p` 的完整网页并在 Chrome 中成功打开（应用）；
3. 能说出 Web 标准三部分（结构 HTML / 表现 CSS / 行为 JS）的名称与作用（记忆）。

## 四、前置知识
无（零基础入口课）。仅需会基本的 Windows 文件操作；如有学生不会"显示文件扩展名"，课前 5 分钟补：资源管理器→查看→勾选"文件扩展名"。

## 五、老师怎么讲（讲授要点 + 时长）
| 环节 | 内容 | 时长 |
|---|---|---|
| 导入 | 打开 2 个热门网站 → 右键"查看网页源代码"："网页的本来面目就是这些文字" | 5′ |
| 讲授1 | Internet vs WWW（WWW 只是 Internet 的服务之一）；请求—响应流程板书：输入地址→请求→响应→传回→显示 | 10′ |
| 讲授2 | HTML 是什么（超文本=带链接的文本、网状结构）；Web 标准三层（预告第3章 CSS、第7章 JS） | 10′ |
| 讲授3 | 标记符语法四条：`<>` 括起、成对出现（结束多 `/`）、属性 `属性="值"`、小写约定 | 10′ |
| 讲授4 | 最小骨架讲解（见演示代码）；title 显示在标签页；meta charset 解决中文乱码 | 5′ |

## 六、老师怎么演示（15′）
分步演示（每步保存刷新让学生看到变化）：
1. 桌面新建文本文件，改名 `myfirst.html`（强调扩展名、命名规范：英文有意义）；
2. 记事本输入最小骨架（注释版）：

```html
<!doctype html>
<html>
<head>
  <meta charset="UTF-8">   <!-- 防止中文乱码 -->
  <title>我的第一个网页</title>  <!-- 显示在浏览器标签页 -->
</head>
<body>
  <h1>你好，网页！</h1>     <!-- 一级标题 -->
  <p>这是我写的第一个网页。</p>  <!-- 段落 -->
</body>
</html>
```

3. 保存 → 双击用 Chrome 打开 → 指认标签页标题、页面内容；
4. 回到记事本改 `<h1>` 文字 → **故意不保存直接刷新**（无变化）→ 保存再刷新（变化）——第一次"错一错"；
5. 课堂提问："如果我把 `<meta charset>` 删掉会怎样？"（留作悬念，下次课演示乱码）。

## 七、学生跟着做什么（实操 30′）
任务（L1 模仿级）：仿照演示，制作"自我介绍"网页 `intro.html`，要求：含 h1（姓名）、至少 2 个 p（家乡、爱好）、有意义的 title、1 条 HTML 注释。
- 交付物：`intro.html` 能在浏览器打开且无乱码。
- 巡视检查点：① 扩展名是不是 .html；② 中文标点陷阱（`<`、`"` 必须为英文）；③ 有没有忘记保存。

## 八、什么地方容易出错（预案）
| 错误 | 现象 | 应对话术 |
|---|---|---|
| 存成 intro.html.txt | 双击打开是记事本 | "看你的文件图标——扩展名被藏起来了，去资源管理器显示它" |
| 中文引号/书名号当标记 | 页面显示原始代码文字 | "标记符号只认英文键盘的尖括号" |
| 改完没保存就刷新 | 页面没变化 | "星号/未保存——养成 Ctrl+S 的肌肉记忆" |
| title 写"首页" | —— | "标签页上写'首页'，一个月后你还找得到它吗？" |

（更多见 `teaching/error-clinic.md`）

## 九、如何检查是否学会（形成性评价 10′）
- 快问快答（教材练习题改编）：① 记事本能编辑 HTML 吗？（√）② title 标记符和 title 属性是一回事吗？（×）③ 解决中文乱码的 meta 写法？④ Web 标准三部分？
- 验收勾选：网页能打开 ✓ 无乱码 ✓ title 有意义 ✓ 含注释 ✓

## 十、如何衔接下一节课
承上："今天你的网页只有标题和段落，还很朴素。"启下："下次课我们学更多文本标记和**超链接**——让你的页面之间能互相跳转，那才是真正的'网'。"
课后作业（分层）：
- 基础：把 intro.html 扩充到 5 个段落，用 `&lt;` 在页面中显示出一个真实的 `<p>` 字样（提示：字符实体）；
- 提高：预习 1.3 节，尝试在网页中插入一张图片（下节课讲注意事项）；
- 挑战：写 200 字"我的网站规划"（主题/给谁看/放什么内容）——教材第1章综合实践①。
