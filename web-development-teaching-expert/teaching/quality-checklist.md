# 教学质量检查清单（quality-checklist）

> 交付任何教学产物（教案/PPT/代码/项目/试卷）前逐项自查；也用于期末课程复盘。

## 教案自查（对应 lesson-plan-spec 十问）
- [ ] 十问全部回答，无空项
- [ ] 目标可测量（行为动词 + 验收标准），非"了解/掌握"空话
- [ ] 实操时间 ≥ 1/3
- [ ] 易错点预案来自 error-clinic 且与本次 KP 对应
- [ ] 有与上节回顾和下节衔接

## 代码教学自查（对应 code-teaching-spec）
- [ ] 示例在浏览器实际运行过（或已按教材原文核对）
- [ ] 完整骨架 / 片段注明插入位置
- [ ] 有逐行解释、运行方式、"改一改"任务
- [ ] 无废弃标签属性；旧写法已标注现代替代
- [ ] 中文注释、2 空格缩进、英文文件名

## 实操项目自查（对应 practical-project-spec 11 要素）
- [ ] 11 要素齐全
- [ ] 步骤可独立验证（每步有中间结果）
- [ ] 验收标准可勾选、可观察
- [ ] 有拓展挑战

## 考核自查（对应 assessment-spec）
- [ ] 三层难度齐全，基础层源自教材练习且答案经核对
- [ ] Rubric 四维度权重明确
- [ ] 上机题提供素材包与验收清单

## 技术准确性自查
- [ ] 引用教材处标了章号，行号可回溯到 full_text.txt（若已清理则标"据教材第N章"）
- [ ] 涉及时效技术（jQuery/Bootstrap 版本、IE、DW 版本）有提示
- [ ] 未联网时未声称"符合最新规范"
- [ ] 无法核对处标"待人工核对"，未虚构页码/章节/案例

## 课程复盘（每学期末，能力H）
- [ ] 汇总各次课作业正确率，定位薄弱 KP
- [ ] error-clinic 新增条目入库
- [ ] 课时分配调整写回 course-map
- [ ] 学生项目中的优秀作品转为下一届演示案例
