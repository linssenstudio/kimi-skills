# 实操项目生成规范（practical-project-spec）

> 能力E。任何课堂实操/项目任务必须包含以下 11 要素，缺一即不合格。
> 素材来源：各章"综合实例/课堂演示点"、ch09 综合实践、ch10 期末项目。

## 11 要素模板

1. **项目任务**：一句话说明做什么（如"制作含导航条的个人简介页"）。
2. **最终效果描述**：页面长什么样、有什么交互；给出效果图描述或线框说明。
3. **项目文件结构**：目录树（默认 `index.html + css/ + js/ + images/`，见 patterns#14）。
4. **环境和工具要求**：浏览器（Chrome/Edge）、编辑器（记事本/VS Code/DW，按课程阶段），是否需要本地站点。
5. **每一步操作方法**：编号步骤，每步可独立完成并看到中间结果（脚手架式：步子要小）。
6. **完整代码**：符合 code-teaching-spec；分文件给出。
7. **运行与预览方法**：保存位置、打开方式、预期显示。
8. **关键知识解释**：本项目用到哪些 KP（列编号），每处代码为什么这样写。
9. **典型错误与处理**：从 error-clinic 选本项目高发的 2–4 条，写清现象→原因→改法。
10. **完成验收标准**：可勾选清单（功能项 + 质量项），如"链接全部有效""图片均有 alt""窗口缩至 768px 布局不破坏"。
11. **拓展挑战任务**：1–2 个进阶方向（如加媒体查询、把导航改 Bootstrap navbar、用 showHide 模式做 Tab）。
