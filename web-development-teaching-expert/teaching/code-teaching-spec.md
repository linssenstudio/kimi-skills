# 网页代码教学规范（code-teaching-spec）

> 能力D。所有面向学生的 HTML/CSS/JS 示例代码必须满足本规范。

## 四条铁律

1. **最小可运行**：示例保存双击即可在浏览器看到效果；HTML 示例须含完整骨架（doctype/head/meta charset/title/body），除非讲解片段本身（片段须注明插入位置）。
2. **逐行解释**：每段代码配"这段代码做了什么"的逐行/逐块说明，用初学者语言，先讲"做什么"再讲"怎么写"。
3. **给出运行方式**：明确"保存为 xx.html 双击打开"或"放入站点 css/ 目录后在 HTML 中 link"等；JS 示例说明脚本放置位置（body 末尾优先，解释 DOM 加载时机）。
4. **遵守 Web 标准**：内容与表现分离；不用废弃标签与属性（`<font>`、`<big>`、`align`、`bgcolor`）；教材案例含旧写法时，保留原样并并列给出现代写法与说明（见各章"时效提示"）。

## 教学呈现顺序（每个示例）

```
效果先行（先展示运行结果截图描述/让学生打开看）
→ 整体结构（哪几部分，各自职责）
→ 逐行讲解（配注释版代码）
→ 改一改（给学生 1–2 个参数修改任务，立即看到变化）
→ 错一错（展示一个常见错误写法及现象，见 error-clinic）
```

## 代码风格

- 2 空格缩进；标签小写；属性值加双引号；CSS 每条声明一行；中文注释解释关键行。
- 命名：英文小写 + 连字符（`main-nav`）；课堂强调文件名不用中文（教材 ch10 案例用中文文件名，作为讨论点讲清楚利弊）。
- 注释密度：初学者示例注释覆盖率 ≥50% 行。

## 难度分级

- L1 模仿级：照抄改文字；L2 拼装级：给零件自己组合；L3 设计级：只给效果要求与验收标准。课堂示例用 L1，练习用 L2，作业/考核用 L3（衔接 assessment-spec）。
