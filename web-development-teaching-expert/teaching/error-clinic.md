# 常见错误诊断库（error-clinic）

> 能力F：教学答疑。按"症状 → 可能原因 → 排查步骤 → 讲解要点"组织，供答疑与教案"易错点预案"使用。来源：各章反模式汇总。

## HTML 类

| 症状 | 可能原因 | 排查与处理 |
|---|---|---|
| 中文全部乱码 | 缺 `<meta charset="utf-8">` 或文件保存编码不是 UTF-8 | 看 head 第一行；另存为时选 UTF-8（ch01） |
| 链接点击 404 / 死链 | 相对路径层级错；文件名大小写；在资源管理器改过文件名 | 数清楚当前页所在层级，`./` 与 `../` 区别（ch02/ch10）；DW 站点内改文件名可自动更新（ch09） |
| 图片显示裂图小图标 | src 路径错、扩展名错（.jpg/.jpeg）、文件没放进 images/ | F12 Network 看 404；DW 链接检查器查"断掉的链接"（ch04/ch09） |
| 锚点跳转没反应 | href 写成 `# top`（含空格）或目标元素没设 id | `#` 与锚点名之间不能有空格；跨页写法 `page.html#top`（ch02/ch09） |
| 单选按钮可以多选 | 各按钮 name 不相同 | 同组单选必须同名（ch05/ch09） |
| 表单嵌套后内层不提交 | `<form>` 里又放了 `<form>` | 表单禁止嵌套，合并为一个（ch05） |
| 标签没闭合/属性引号没闭合，后面全乱 | 结束符缺失 | DW Linting/输出面板定位行号（ch09）；讲标签配对纪律（ch01） |

## CSS 类

| 症状 | 可能原因 | 排查与处理 |
|---|---|---|
| 样式完全没生效 | 没 link 上 CSS 文件；选择器拼写；类名漏点号 `.` | F12 Elements→Styles 看规则是否出现（ch03） |
| 样式被别的规则覆盖 | 优先级/层叠顺序问题 | 用开发者工具看哪条规则划线；页内 style 要在 link 之后（ch03/ch09） |
| 浮动后父元素高度塌陷 | 未清除浮动 | 加 clear 元素/伪元素清除法（ch06） |
| 浮动元素换行错位 | 总宽度超过容器；margin 计算错 | 检查盒模型与 box-sizing（ch06） |
| 悬停时布局跳动 | :hover 新增了边框改变了盒尺寸 | "占位边框"技巧：默认加同色 border（ch10 patterns#9） |
| 响应式断点不生效/互相覆盖 | 媒体查询顺序错 | max-width 方案从大到小排列（ch09 教材原文警告） |
| 响应式图片被拉伸变形 | 只设了 width 没设 height:auto | `width:100%;height:auto`（ch09/ch10） |

## JavaScript 类

| 症状 | 可能原因 | 排查与处理 |
|---|---|---|
| 控制台报 null，操作无效 | 脚本在 DOM 加载前执行；getElementById 的 id 拼写错 | 脚本放 body 末尾或 DOMContentLoaded；核对 id 大小写（ch07） |
| 判断永远不成立/永远成立 | 把 `==` 写成了 `=`（赋值） | 比较用 `==`/`===`；讲赋值与比较区别（ch07） |
| switch 穿透执行 | 忘写 break | 每个 case 后 break（ch07） |
| 交互组件全部同时显示/隐藏 | 缺少"先复位再显示当前"逻辑 | showHide 模式：循环复位全部→显示目标项（ch10 patterns#10） |
| 函数没执行 | 事件属性拼写（onclick 大小写）；函数名调用时多了/少了括号 | F12 Console 报错信息；元素事件绑定检查（ch07） |

## 答疑话术原则

不给直接答案，按三级提示递进：① 指方向（"问题在链接这一行"）→ ② 给方法（"用 F12 看 Console 报什么"）→ ③ 才给改法。每次答疑后把新错误类型补入本库（课程迭代）。
