# 课程地图与知识依赖图（course-map）

> 能力A：课程规划。输入学生基础、总学时、教学目标 → 输出大纲、模块划分与课时安排。

## 知识依赖图（前置关系）

```
ch01 运行原理与HTML骨架
 └─ ch02 文本与超链接（依赖：标记语法）
     └─ ch03 CSS基础（依赖：标记符、class/id 概念）
         ├─ ch04 图像（依赖：标记+路径，可与ch05并行）
         ├─ ch05 表格与表单（依赖：标记+路径）
         └─ ch06 CSS进阶布局（依赖：选择器、盒模型初识）
             └─ ch07 JavaScript与DOM（依赖：HTML结构熟练；id/class）
                 └─ ch09 工具与响应式实操（依赖：ch03/06/07 全部）
                     └─ ch10 综合项目（依赖：全书）
ch08 设计基础：无技术前置，建议在布局(ch06)之后、综合项目之前讲，也可提前穿插
```

## 学情调整规则（能力H：课程迭代）

- 前测发现学生零基础且计算机操作弱：阶段 1–2 各加 1 次课，图像/表格压缩为 1 次。
- 作业正确率 <60% 的知识点：下次课开头 10′ 重做演示 + 变式练习，再把该 KP 加入后续课的"回顾页"。
- 学生普遍超前：ch09 工具章压缩，把课时让给 ch10 项目与 Bootstrap 5 拓展。
- 每次答疑/批改发现的新错误类型，补入 `error-clinic.md`；每轮授课结束更新本文件课时分配。
- 40/48/64 学时变体：按比例扩展实操与项目课时，讲授总时长不超过 50%。
