# 教学模式库（Patterns）

> 从教材提炼的可复用教学/工程模式。每条含：名称 → 问题 → 做法 → 教材出处 → 课堂用法。

## 教学设计模式

1. **实战驱动 + 分散学习 + 自成目的**（教材前言三原则）
   问题：零基础学生学标记语言易枯燥遗忘。做法：每知识点挂在一个可见的网页效果上；大知识点拆到多次课复现（如列表在第2章学语法、第6章做导航条、第10章做分页）；让学生作品本身成为学习动机。
2. **"界面操作 ↔ 生成代码"对照法**（ch09）
   问题：用 DW 的学生离开工具就不会写代码。做法：每次可视化操作后切"代码"视图核对生成的 HTML/CSS，建立双向映射。
3. **先手写后工具**（ch01→ch09 的顺序本身）
   问题：工具替代理解。做法：前 7 章全部手写代码并浏览器预览，第 9 章才引入 DW 提效——"工具帮助已掌握者提高效率"。
4. **错误教学法**（各章"常见错误"）
   做法：演示故意写错的代码（死链、裂图、表单嵌套、忘 clear），让学生观察现象→猜原因→修正，比直接讲正确写法印象深。
5. **模板先行**（ch10）
   做法：项目先做 1 个模板页（含公共结构+样式），师生评审认可后再铺开其余页面——工程上的"原型确认"，教学上的" Checkpoint 形成性评价"。

## 工程技术模式

6. **Web 标准三层架构**（ch01/ch03/ch07）
   结构 HTML / 表现 CSS / 行为 JS 分离。落地规则：不用 `align`/`bgcolor` 等表现属性、不用 `<b>` 表达"重要"、CSS 一律外部文件、JS 尽量外置。
7. **分层样式表架构**（ch06/ch09/ch10）
   全站公共样式放 base.css/main.css（导航、页脚、字体基调），页面特定样式放 index.css/pages.css；页内 `<style>` 仅用于该页独有规则且置于 `<link>` 之后。优点：风格统一、改一处全站生效、缓存友好。
8. **导航条 CSS 化**（ch02→ch06→ch10）
   演进路线：文字+`|`分隔（ch02）→ 无序列表+CSS（`ul>li` + `display:inline-block` 或 float）→ Bootstrap navbar 折叠响应式（ch10）。课堂可串成"同一需求的三个时代"。
9. **悬停下画线的"占位边框"技巧**（ch10）
   给 `nav a` 默认加与背景同色的 `border-bottom`，悬停时只改颜色——避免悬停瞬间盒子尺寸跳动。延伸：所有 :hover 效果都应问"会不会引起布局抖动"。
10. **CSS 默认状态 + JS 复位后单项显示**（ch10 showHide）
    交互组件模式：CSS 定默认显示项（`#skill1{display:block}` 其余 none），JS 先循环复位全部、再显示目标项。适用于 Tab、手风琴、图库切换。
11. **四步造表法**（ch05）
    `<table>` 定框 → `<caption>` 写标题 → `<th>` 表头行 → `<tr><td>` 逐行填充；合并单元格只能合并连续区域（rowspan/colspan）。
12. **表单三段式**（ch05/ch07）
    结构（`<form action method>` 包控件，禁止嵌套）→ 可用性（`<label for>` 关联、name 分组单选）→ 校验（HTML5 type=email/required 原生校验优先，JS 校验补充）。
13. **图像选型决策**（ch04）
    照片渐变 → JPEG；图标透明 → PNG；动图 → GIF；矢量 Logo → SVG；现代格式 WebP 作拓展。配 `alt` 与尺寸声明。
14. **相对路径纪律**（ch02/ch10）
    根目录页面用 `./`，子目录页面用 `../`；全站统一 `html/ css/ js/ images/` 四目录结构；改文件名只在 DW"文件"面板内操作以自动更新链接。
15. **响应式三件套**（ch07/ch09/ch10）
    viewport meta → 流式尺寸（%/auto，图片 `max-width:100%`）→ 断点媒体查询（max-width 从大到小排列，顺序错了样式覆盖出错）或直接 Bootstrap 栅格。
16. **网站规划四步**（ch10）
    目标（成文）→ 目标用户 → 风格（KISS）→ 技术因素（带宽/浏览器/分辨率）→ 信息架构。期末项目策划书即按此骨架。
17. **导航设计三件套**（ch08/ch10）
    主导航（全局、顶部、当前态标识）+ 面包屑（位置感知"首页 > 栏目 > 页面"）+ 页内/分页导航（pagination）；验收用"后备箱测试"。
