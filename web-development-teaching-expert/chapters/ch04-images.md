# 第4章 图像

> 教材定位：第1部分第4章 | 前置：ch02（路径）、ch03（CSS 属性）

## 核心思想
网页图像 = 选对格式（GIF/JPEG/PNG）+ 用 Photoshop 处理好（小文件、透明、抠图）+ 用 `<img>` 插入 + 用 CSS 修饰。本章是唯一包含桌面软件操作的章节，同时教学"代码复用"思想。

## 教学目标（教材原文）
- 知识：区分位图/矢量图；区分 GIF/JPEG/PNG；掌握 `<img>` 用法
- 技能：遵循图像使用原则；Photoshop 基本操作；`<img>`+CSS 插入与修饰图像；制作多媒体网站
- 素养：专业工具的工程应用；中国符号网站（中华文化）；"代码复用"

## 知识点

### KP4.1 位图 vs 矢量图（4.1.1）
- 位图：像素网格组成（马赛克类比），编辑即改像素；软件：Photoshop、画图、美图秀秀
- 矢量图：数学线条/曲线描述，文件小、缩放不失真、与分辨率无关；软件：Illustrator、CorelDRAW（Flash 是基于矢量图的动画软件）
- 考试点：矢量图通常比位图文件小；Flash 不是位图软件

### KP4.2 三种网页图像格式（4.1.2）—— 选择决策（教学核心表）
| 格式 | 压缩 | 颜色 | 透明 | 动画 | 适用 |
|---|---|---|---|---|---|
| GIF | 无损 | ≤256 色 | 透明色（只能 100% 透明） | 支持 GIF 动画（多帧） | 标题文字、按钮、小图标、线条图 |
| JPEG | 有损（可控压缩比） | 真彩色无限制 | ✗ | ✗ | 照片、渐变色图像 |
| PNG | 无损 | 任意 | 支持 0%–100% 半透明 | ✗ | 需要透明/半透明；文件比 GIF/JPEG 大 |
- ⚠ 不能靠改扩展名转换格式（要用软件导出）

### KP4.3 图像使用三原则（4.1.3）—— 设计素养考点
1. **确保文件较小**：像素尺寸合适 + 正确格式优化
2. **控制数量和质量**：初学者最易犯"堆图"错误；两个自问——有助于传达主题吗？设计与属性有助于统一风格吗？
3. **合理使用动画**：页面动画不超过 3 处，最好一两处画龙点睛；滥用会"吓跑"浏览者

### KP4.4 Photoshop 基本操作（4.2，以 CC 2019 为例）
- 界面：菜单栏/工具箱（长按右键出更多工具）/选项栏/图像窗口/状态栏/选项面板
- 改大小：图像→图像大小；**保持"约束长宽比"（铁链图标）防止变形**
- 调颜色：图像→调整→亮度/对比度、色相/饱和度；配合选区可局部调色（"染发"案例）
- 撤销：Ctrl+Z；窗口→历史记录面板
- 擦除工具组：橡皮擦（填充背景色/透明）、背景橡皮擦（擦成透明+背景层转普通层）、魔术橡皮擦（点选相近色）
- 仿制图章：按住 Alt 取样→拖曳复制；用于消除图像内容（消除大雁案例）；图案图章：先"编辑→定义图案"再涂抹
- 修复画笔：Alt 取样，自动匹配纹理/光照/阴影，无痕修复
- 抠像：快速选择工具/魔棒选相近颜色区域；Alt 减选区；画笔大小调小（如 5px）更精确；Delete 填充白色得抠图；Ctrl+D 取消选区；选择→反选

### KP4.5 按格式导出（4.2.5）
- JPEG：文件→存储为→JPEG→调"品质"；建议保留原始副本
- GIF（透明）：文件→导出→导出为→GIF
- PNG（半透明）：图层面板"不透明度"如 80% → 文件→导出→快速导出为PNG；原透明区域保持全透明，其余半透明

### KP4.6 `<img>` 标记符（4.3.1）—— 核心语法
- 自结束标记符；**src 和 alt 两个必要属性**：src=文件路径（复习相对/绝对路径），alt=替换文本（图像无法显示时显示）
- ⚠ 最典型错误：裂图图标+替换文本 → src 路径或文件名错误（含扩展名写错）
- `<img src="sunset.jpg" alt="大漠孤烟直，长河落日圆" />`

### KP4.7 图像的 CSS 修饰（4.3.2）
- width/height 属性：预留空间加速加载；只给一项按比例缩放，两项都给可能变形；⚠ **不要用 width/height 缩小图像**（文件大小没变）——先用 PS 改像素
- ⚠ HTML5 中 img 的 align/border/hspace/vspace 属性已不支持 → CSS
- 边框：`img{border:1px solid black;}`
- 周围空白：margin/padding（第6章）
- 水平对齐：img 是行内元素，无"水平对齐"；须放在块元素里对块设 `text-align:center`
- 垂直对齐：`vertical-align: top|middle|bottom`（图文行内对齐）
- 图文混排：`float:left/right` + margin（第6章详述）
- 透明度：`opacity:0.4`，悬停 `img:hover{opacity:1.0}`；⚠ `filter:alpha(opacity=40)` 是 IE8 及更早的兼容写法，现代教学可不讲（教材仍保留）

## 综合实例：中国符号网站（4.4）—— "代码复用"教学案例
- 明确复用 3.5 电影欣赏网站代码，让学生对比异同（教学设计亮点）
- 5 栏目：古代神话/人物传说/花卉植物/文玩雅赏/自然文化
- 新增视觉效果：页脚 border-top 分隔线；透明 PNG 圆形/圆角图；`.pics{opacity:0.4}` + `.pics:hover{opacity:1.0}` 动态效果；**首字下沉** `#first_char{float:left; font:32px楷体;}`
- 圆形抠图流程：椭圆选框(Shift)→反选→解锁背景层→Delete→导出 PNG
- 圆角矩形抠图：矩形选框+魔棒(Alt 减选四角)→反选→解锁→Delete→导出 PNG
- 技能拓展：嵌入音频/视频（多媒体对象）

## 反模式
- 堆砌大量图片/动画（数量失控）
- 用 width/height 属性"缩小"大图（文件没小，加载仍慢）
- 改扩展名冒充格式转换
- 忘记约束长宽比导致变形
- img 无 alt 属性
- 图片路径写错（裂图）

## 教材练习题（考核素材）
- 判断：只有 GIF 能透明（×，PNG 也行）；img 的 align 居中（×）；opacity:0 是不透明（×，是全透明）
- 单选：JPEG "最多1024色"错误；可用软件改像素大小（√）
- 填空：GIF 特点（≤256色/透明色/动画）；跨目录插图路径（考相对路径）；背景音乐 embed/audio
- 综合实践：①自拍→PS处理（至少改像素）→插入简历页 ②给两个既有网站加图片+CSS修饰+至少一处音视频 ③互评（组员须换）

## 验收标准
- 能按内容类型正确选择 GIF/JPEG/PNG 并说明理由
- 能用 PS 完成改大小、抠图、导出透明 PNG 全流程
- 能写出含 alt 的 img 并用 CSS 完成边框/对齐/环绕/半透明效果
