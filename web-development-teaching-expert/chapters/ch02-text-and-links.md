# 第2章 文本格式与超链接

> 教材定位：第1部分第2章 | 前置：ch01（网页骨架、标记符语法）
> 原文核对：full_text.txt 行1211–2491

## 核心思想
文本格式建立网页的**逻辑结构**（不是视觉效果），超链接把页面组织成网站。本章产出第一个多页面网站（唐诗宋词网站）。

## 教学目标（教材原文）
- 知识目标：`<p>`、`<h1>`～`<h6>`、`<hr>` 用法；区分物理/逻辑字符样式；`<ol>`、`<ul>`、`<li>`；区分绝对/相对 URL；`<a>` 与站内/站外/锚点链接
- 技能目标：建立文本结构、有序/无序/嵌套列表、各种超链接，创建基于文本的多页网站
- 素养目标：工匠精神（细节决定成败）；唐诗宋词网站增强传统文化认同

## 知识点

### KP2.1 段落格式（2.1.1）
- `<p>` 分段 vs `<br>` 段内强制换行（自结束，`<br>` 或 `<br/>`）
- **规范原则（必考）**：逻辑上是段落的内容必须用 `<p>`，不要用 `<br>` 断开——保证逻辑含义正确、结构严谨
- `<h1>`～`<h6>` 按**逻辑层级**使用，不是为字号效果（字号交给 CSS）；`<h2>` 须在 `<h1>` 之后
- `<hr>` 水平线（自结束）；属性 size（粗细px，默认2）、width（px或百分比）、noshade（布尔属性：属性值与属性名相同）
- align 属性：left/right/center/justify；默认：`<p>`、`<hn>` 为 left，`<hr>` 为 center；justify 多数浏览器不支持
- ⚠ 过时标记：align 属性与 hr 各属性在 Web 标准中已废弃 → CSS 替代（教材明确：仅作调试权宜之计）

### KP2.2 字符样式：物理 vs 逻辑（2.1.2）
- 物理字符样式：标记符说明显示效果，如 `<b>` 粗体、`<sub>` 下标（H`<sub>2</sub>`O）
- 逻辑字符样式：标记符表达逻辑含义，如 `<strong>` 重要、`<em>` 强调、`<mark>` 标注、`<address>` 地址
- **内容与表现分离原则（核心考点）**：优先逻辑样式；HTML5 中 `<b>` 只作最后选项；用 `<strong>` 替代 `<b>`、`<em>` 替代 `<i>`
- 示例：`<p>这里是<strong>需要强调的内容</strong></p>`

### KP2.3 列表（2.1.3）
- 有序列表 `<ol><li>`：表顺序关系（如操作步骤）；type 属性改编号样式（如 `type="I"` 大写罗马数字）→ 建议 CSS 替代
- 无序列表 `<ul><li>`：表并列关系；**导航条本质是无序列表**（第6章讲横向化）；type = disc（默认实心圆）/circle/square
- 嵌套列表：有序无序可互相嵌套
- 课堂示例（教材原文）：王者荣耀入门——`<ol>` 内嵌 `<ul type="square">` 列英雄分类

### KP2.4 URL 与路径（2.2.1）—— 学生最易错点
- URL 三部分：协议 + 计算机地址 + 文件路径；常见协议 http、ftp、mailto、news、telnet
- ⚠ HTML 中目录分隔用斜杠 `/`，不是 Windows 的反斜杠 `\`
- 绝对URL：`协议://域名/路径文件名`，用于**站外**资源
- 相对URL：相对当前页面的路径，用于**站内**；`.` 当前目录（可省），`..` 上一级目录
- 为什么用相对URL：站点移植（上传服务器/U盘）时保持相对位置即可，链接不失效

### KP2.5 页面链接（2.2.2）
- `<a href="目标">源对象</a>`，源可以是文字或图像
- href 指向浏览器能显示的格式 → 直接打开；指向不能识别的格式（如压缩包）→ 触发下载
- 超链接默认样式：蓝色+下划线，悬停变手形
- ⚠ 最常见错误：href 指定的文件不存在 → 死链（教材强调"最常见错误之一"）
- 电子邮件链接：`<a href="mailto:someone@263.net">`
- 空链接占位符：`href="#"`（大网站开发中常用）

### KP2.6 锚点链接（2.2.3）
- 两步：① 定义锚点 `<a name="top" id="top">目录</a>`（name+id 同写为兼容，HTML5 已不支持 name，现代实践只用 id）② 链接 `<a href="#top">返回目录</a>`
- 跨页锚点：`<a href="图2-5.htm#yyjb">夜雨寄北</a>`
- ⚠ href 单独的 `#` 是空链接不跳转，`#名称` 才是锚点

## 综合实例：唐诗宋词网站（2.3，第一个完整多页项目）
- 网站规划流程（教学方法论）：确定站点目标 → 内容组织（栏目→作者）→ 文件结构（tangshi/ 目录 + images/ 文件夹）→ 导航系统设计
- 导航系统四层（教学设计重点）：**主导航**（首页|唐诗|宋词，页顶）→ **面包屑**（您的位置：首页>唐诗>李白）→ **二级导航**（栏目内页面）→ **页脚导航**（同主导航，小号字体）+ 内容页锚点链接
- 文件结构：根目录 index.htm + tangshi/index.htm（二级）+ tangshi/libai.htm（三级）+ images/
- 关键技巧：同级目录用 `href="libai.htm"`；回根目录用 `href="../index.htm"`；未做页面用 `href="#"` 占位；当前页导航项用 `<strong>` 标出
- `<div align="center">` 块级包含（div 首次出现，第6章深入）
- 用 `<p>&nbsp;</p>` 加空白是过渡写法，学 CSS 后废弃（教材原注）

## 反模式
- 用 `<br>` 分段落（应用 `<p>`）
- 为字号效果乱用 `<hn>`（应按逻辑层级）
- 路径用反斜杠 `\`
- 站内链接用绝对URL（导致移植后死链）
- 使用 `<font>` 标记符（已废弃，练习题答案点）
- 物理样式 `<b>`/`<i>` 优先于 `<strong>`/`<em>`

## 教材练习题（考核素材）
- 客观题：划分段落应用 `<p>` 而非 `<br>`（√/×题）；hr 粗细是 size 不是 width；hr 默认 align=center；无序列表用 `<ul>`+`<li>`；`<font>` 已废弃；href 不能是任意字符串；强调粗体最好用 `<strong>`
- 填空：跨目录链接写法（考相对路径）
- 综合实践：①个人简历页 resume_姓名.html（hn/p/hr+至少一种列表）②完善唐诗宋词网站（+3页，风格一致，链接正确）③仿制完整网站 ④两人互评

- 能制作含锚点目录的长页面
