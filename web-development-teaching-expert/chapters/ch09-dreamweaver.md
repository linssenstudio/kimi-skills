## 核心思想

1. **"所见即所得"工具的内在逻辑**：DW 的设计/实时视图本质是 HTML+CSS 的可视化映射——每一个面板操作都对应具体代码（"属性"检查器的"格式"下拉 = <p>/<h1>-<h6>，B 按钮 = <strong> 等）。教学关键：**让学生建立"界面操作 ↔ 生成代码"的对照意识**，通过切换到"代码"视图验证操作结果。这是素养目标1 的直接落点。
2. **站点优先**：使用 DW 制作网站的**首要操作是建立站点**（教材原话 9.2.1）。建立站点后所有文件操作（新建/删除/重命名）都应在 DW 中进行，DW 才能自动维护超链接——这是工具价值的核心体现。
3. **工具是效率手段，不是替代品**：章首明确 DW"能帮助熟练掌握 HTML 和 CSS 的开发者提高效率"——教学顺序必须是先手写代码、后用工具提速，不能颠倒（否则会培养出离开 DW 就写不出网页的学生）。素养目标2："工程实践中最关键的因素是人，人能通过使用先进工具提升效率"。

## 教学目标（教材原文）

- 知识：了解 DW 基本界面元素；理解站点概念；掌握在 DW 中使用 CSS 的方法；理解响应式设计概念。
- 技能：熟练掌握站点创建与管理、网页编辑、CSS 应用流程、响应式设计；掌握快速代码编写、Bootstrap、jQuery 应用；能用 DW+Bootstrap 做响应式网站。
- 素养：理解"所见即所得"工具的内在逻辑；体会人用先进工具提升效率；通过响应式开发理解软硬件互相促进与"以人为本"。

## 知识点

### KP-9.1 DW 界面与视图
- 界面元素：应用程序栏、文档工具栏（设计/实时/代码视图切换）、通用工具栏、"文档"窗口、状态栏（**标签选择器**显示当前标签层次、窗口大小设置、预览按钮）、工作面板（"插入"/"文件"/"CSS设计器"）。隐藏全部面板快捷键 F4。
- 三种视图：**设计视图**（可视化编辑）、**代码视图**（手写代码）、**实时视图**（接近真实浏览器渲染）。练习1 考点：实时视图与设计视图功能不一样。
- 工作区布局可在右上角"工作区切换器"切换。
- 课堂演示：打开同一页面在三种视图间切换，改一处看两处同步变化。

### KP-9.2 本地站点：创建与文件管理
- 概念：站点 = 位于特定文件夹（站点文件夹）的一系列文件；建立站点是 DW 开发网站的首要操作。
- 创建步骤（可投影操作）：站点→新建站点 → 输入站点名称 → 指定本地站点文件夹 → 高级设置中设**默认图像文件夹**（images）→ 保存。
- 站点文件操作惯例：根目录建 index.html（首页，扩展名默认 .html）、建 html/css/js 三个子目录分类存放。
- 铁律（教材强调两次）：建立站点后，**所有文件操作都在 DW 中进行**，不要在资源管理器里改文件名——否则超链接不会自动更新。
- 常见错误：学生绕过 DW 在资源管理器移动文件 → 全部死链。这恰好是教学契机：演示错误后果，再演示"文件"面板内改文件名时 DW 弹"更新文件"对话框自动修复链接（9.3.3-4）。

### KP-9.3 网页元素的可视化编辑
制作网页一般过程：建站点 → 打开/新建网页 → "页面属性"设标题/编码与外观 → Ctrl+S 保存 → 设计视图输入内容（Enter 换段 = <p>）→ 选中后用"属性"检查器修饰 → **先保存再按 F12 预览**（标签文件名后有 * 表示未保存）。可设 Chrome 为主浏览器 F12、Firefox 次浏览器 Ctrl+F12。

各元素操作要点（全部有 HTML 代码对照，见下表）：

| 元素 | DW 操作 | 对应代码（见"代码"视图） |
|---|---|---|
| 段落/标题 | "属性"检查器"格式"下拉 | `<p>` / `<h1>`–`<h6>` / `<pre>` |
| 粗体/斜体 | B / I 按钮 | `<strong>` / `<em>` |
| 列表 | 列表按钮+"列表项目" | `<ul>/<ol>` + `<li>` |
| 页面链接 | "链接"框输 URL / 浏览文件 / 拖"指向文件" | `<a href>`；站内用相对 URL |
| 锚点链接 | 先给目标文本设 ID，再链接 `#锚点名` | `<a href="#top">`、`tob.html#top` |
| 邮件链接 | "插入"面板→电子邮件链接 | `<a href="mailto:...">` |
| 图像 | 插入→图像（Ctrl+Alt+I），非站点文件自动存入 images | `<img src alt width height id>` |
| 鼠标经过图像 | 插入→HTML→鼠标经过图像 | `<a>` 内嵌 `<img>` + onMouseOver/onMouseOut 自动生成 JS（练习题4 考点） |
| 音频/视频 | 插入→HTML→HTML5 Audio/Video | `<audio>`/`<video>` |
| 表格 | 插入→Table 对话框（行列数/宽度/边框/单元格边距=cellpadding/间距=cellspacing/标题=<th>/辅助功能=<caption>+summary） | 见第5章 |
| 表单 | 插入→表单→表单（虚线黑框=作用范围），再插控件；Action 指定服务器端处理程序，Method 一般选 POST | `<form>` + 控件；表单内不能嵌表单 |
| 文本框/密码/文本区域 | "文本"/"密码"/"文本区域"按钮 | `<input type=text/password>` + `<label>` / `<textarea>` |
| 复选框/单选按钮 | 用"复选框组"/"单选按钮组"一次插入多个 | 单选按钮**必须 name 相同**才有单选效果（单独插入时要手动统一 name） |
| 按钮 | 按钮/提交按钮/图像按钮 | `<input type=button/submit/image>` |

表格选取技巧：单击边框选整表（或用状态栏标签选择器选 `<table>`）；Ctrl+单击选不连续单元格；Shift 选连续区域；行左侧出现黑箭头单击选行；列不能用标签选择器选。合并/拆分单元格："属性"检查器按钮或右键"表格"菜单，**只能合并连续单元格**。

超链接维护：改名/移动文件时 DW 弹"更新文件"对话框自动更新；全站链接检查 = "文件"面板右键→检查链接→整个本地站点，链接检查器可查"**断掉的链接、外部链接、孤立文件**"三类（练习题5 答案 A），引用不存在的图像也算断链。

教材提醒：多数情况下不建议用超链接 target 属性（会造成用户理解混乱）。

### KP-9.4 在 DW 中使用 CSS（CSS 设计器）
- 链接现有 CSS 文件：CSS 设计器"全部"模式 → "源"部分 + 按钮 → "附加现有的CSS文件" → 浏览定位 → 保持"链接" → 确定（生成 `<link>`）。
- 创建新 CSS 文件：同上，选"创建新的CSS文件"，保存到站点 css 目录。
- 定义页内样式："源"→"在页面中定义"（生成 `<style>`，位于 `<link>` 之后）。**注意：必须先链接外部样式表再定义页内样式**，因为页内样式优先级通常高于外部样式表（呼应第3章层叠优先级）。
- 定义规则：选"源"→"选择器"+ 输入选择器 →"属性"部分输入属性和值；可暂时禁用单条属性（调试用）；取消"显示集"可看分类完整属性列表（布局/文本/边框/背景/更多），悬停有提示——教材指出"这其实也是个学习CSS属性的好方法"。
- 应用规则：标记符选择器/纯标记符后代选择器等自动应用；**类/ID 选择器必须手动给元素指定 class/id**——用标签选择器或 DOM 面板选中元素，在"属性"检查器的 Class/Nav ID 下拉中选择（下拉自动列出所有样式表中已有的类与 id）。
- 教材立场：文本"属性"检查器的 CSS 模式直接设格式**不符合"内容与格式分离"原则，不建议使用**。
- CSS 布局模板：文件→新建→启动器模板→基本布局，创建带布局网页+对应 CSS 文件作为修改起点；也可下载网上模板分析学习。

### KP-9.5 高级功能

**emmet 快捷输入**（练习题6 考点：`*` 表示重复元素）：
- HTML：`ul>li*3` +Tab → 一个 ul 含 3 个 li；`ul>li#id$*3` +Tab → 生成 id1/id2/id3 递编号。
- CSS：`m10-a` +Tab → `margin: 10px auto;`；模糊匹配：`ov:h`/`ovh`/`oh` → `overflow: hidden;`。
- 注意：缩写字符之间不要有空格。VS Code 同样内置 emmet；SublimeText 需装插件（教学迁移点：技能可迁移到学生未来用的编辑器）。

**多光标**：Alt+点击/拖动在同列加多光标或选矩形区域；Ctrl 在不同位置加多光标。

**代码片段**：预定义片段双击插入（如 Add a Favicon 插入 favicon 链接——favicon 是标题栏左侧 .ico 小图标）；熟悉触发键后输入触发键+Tab（如 `favicon`、`qtable`）；可自建片段（名称/描述/触发键/插入代码，触发键可以是中文）。**教学价值：把课程常用代码骨架做成自建片段发给学生。**

**快速编辑**：Ctrl+E 进入，直接在 HTML 代码处内联编辑关联的 CSS，无需切换文件。

**代码检查（Linting）**：HTML/CSS 检查自动生效；JS 检查需在"站点设置"→高级→JS Lint 配置。保存后错误行号变红，悬停显示原因，状态栏图标打开"输出"面板列出全部错误。教材实例：nav 结束符少 `>`、class 属性双引号未闭合。

**响应式网页设计**（与 7.3.2 呼应）：
- 定义：网站能根据用户行为和**设备环境（系统平台、屏幕尺寸、屏幕定向等）**自动响应调整（练习题10 答案：系统平台）。移动设备普及使响应式成为基本要求。
- 方法一：样式表内媒体查询。步骤（以把第6章中华美食首页改为响应式为例）：
  1. head 加 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`；
  2. 主导航后加 `<div id="responsive_bread">您的位置：首页</div>`；
  3. CSS 设计器→base.css→"@媒体"添加媒体查询，条件 `max-width: 1000px`；
  4. 媒体查询内写覆盖规则：小屏隐藏固定导航和 footer（`display:none`）、显示面包屑、`#main{width:100%;position:relative;height:auto}`、图片 `width:100%;height:auto`、导航项 `display:inline-block;width:25%`；
  5. 普通规则中反向隐藏面包屑（大屏不显示）；index.css 同样建媒体查询处理图片区（取消 transform 效果等）。
- 媒体查询语法：`@media mediatype and (media feature) { CSS-Code; }`。mediatype：all（默认）/print/screen/speech（练习题7 答案：reader 不是媒体类型）；media feature 最常用 **max-width 和 min-width**（练习题9 答案）。
- 多断点从大到小定义（1200/992/768/480），**顺序不能错，否则样式覆盖出问题**（教材原文警告）。
- 方法二：链接式响应式样式表——创建 CSS 文件时展开"有条件使用"直接挂媒体查询条件，生成带条件的 `<link>`（如 base-responsive.css、index-responsive.css 分离管理）。

**使用 Bootstrap**：
- 文件→新建→启动器模板→"Bootstrap模板"选示例页创建；或新建文档选框架 BOOTSTRAP（站点已有文件时默认"使用现有文件"）；取消"包含预构建布局"得空白 Bootstrap 页。
- 组件化搭建流程（实时视图）：插 Container 容器 → 选中容器插 "Navbar: Inverted Navbar"（选"嵌套"）→ 插 Breadcrumbs（选"之后"）→ 插 Carousel（保存时提示复制相关文件）→ 插 "Grid Row with Column"（设列数 2）→ 输入内容（`lorem`+Tab 生成占位文本）→ 加 footer → 预览（本身即响应式）。
- 借助"插入"面板的"Bootstrap组件"和"代码片段"面板的 Bootstrap_Snippets（注意版本兼容）。
- 版本时效：教材环境为 Bootstrap 4.x（第7章引 4.4.1）；**当前 Bootstrap 已到 5.x，组件类名有变化**（如 `.ml-*`→`.ms-*`，jQuery 依赖移除）。用 DW 内置模板无碍，但引用外部最新文档时注意版本。

**使用 jQuery**：
- jQuery widget：插入面板"jQuery UI"类别→选 Tabs 等构件→保存时"复制相关文件"生成 jQueryAssets 文件夹→修改构件内容。
- jQuery 效果：选中对象→窗口→行为→添加行为→效果（如 Fade）→设参数→可改触发事件（如 onDblClick）→预览。
- 时效警示同第7章：jQuery 语法稳定但生态地位下降，教学应定位为"维护存量代码 + DW 集成体验"，原生 DOM 优先。

## 反模式

- ❌ 绕过 DW 在资源管理器中移动/重命名站点文件 → 超链接全部失效。✅ 一律在"文件"面板操作，让 DW 自动更新链接。
- ❌ 没建站点就开始做网页 → 失去链接管理、检查、模板等全部站点功能。✅ 首要操作建站点。
- ❌ 先定义页内样式再链接外部样式表 → 优先级不符合预期。✅ 先 `<link>` 后 `<style>`。
- ❌ 用文本"属性"检查器的 CSS 模式逐段设置格式 → 违反内容与格式分离，且工作流低效。✅ 用 CSS 设计器建规则、给元素挂 class/id。
- ❌ 媒体查询断点按从小到大顺序书写 → 后写的大断点覆盖小断点规则。✅ max-width 方案从大到小排列（min-width 移动优先方案则相反——讲清覆盖逻辑）。
- ❌ 单独插入多个单选按钮却不统一 name → 可以多选，失去单选语义。✅ 用"单选按钮组"或手动统一 name。
- ❌ 改完代码直接 F12 预览 → 看到的是旧文件。✅ 先 Ctrl+S（文件名后 * 消失）再预览。
- ⚠ 盲目依赖 DW 生成的代码不检查（如鼠标经过图像的 onMouseOver 内联 JS）→ 代码风格旧、难维护。✅ 养成切"代码"视图审查生成代码的习惯。

## 教材练习题（含答案要点）

客观题（教材无答案页，以下为按教材正文推导的答案）：
1. ✗（实时视图接近真实浏览器渲染，与设计视图不同）
2. ✓（编辑网页前应建本地站点）
3. ✓（改名后提示并可自动更新相关超链接）
4. ✓（鼠标经过图像在 head 自动生成 JS 代码）
5. A（断掉的链接、外部链接、孤立文件）
6. B（`*` 表示重复元素；`$` 是递编号）
7. D（媒体类型为 all/print/screen/speech，无 reader）
8. "CSS设计器"面板
9. max-width
10. 系统平台

问答题要点：
1. 建站点的基本过程：新建站点（名称+本地文件夹+默认图像文件夹）→ 建文件结构（index.html + html/css/js 目录）→ 页面属性设标题 → 插入内容并用属性检查器/CSS 设计器修饰 → 保存 → F12 预览 → 链接检查。
2. 代码辅助功能任举两个：emmet 快捷输入、多光标、代码片段、快速编辑（Ctrl+E）、Linting 代码检查、代码提示与完成、代码折叠。
3. 响应式基本过程：加 viewport meta → 建媒体查询（如 max-width:1000px）→ 在媒体查询内写小屏覆盖规则（隐藏元素/宽度百分比/图片自适应）→ 多断点从大到小 → 预览测试；或用 Bootstrap 模板与组件。

综合实践（适合作为机房大作业）：
1. 用 DW 管理之前制作的多个站点，改名/移文件观察链接自动更新。
2. 把中华美食网站所有页面改为响应式，注意复用 CSS。
3. 用 DW 从零新建一个响应式网站（综合全学期内容）。
