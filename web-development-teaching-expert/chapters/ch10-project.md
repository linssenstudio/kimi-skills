## 核心思想

1. **网站开发是工程项目，遵循标准流程**：规划 → 设计 → 开发 → 发布 → 维护，五阶段循环（维护回到规划，周而复始）。素养目标1：借此理解工程实践中的"标准操作规程（SOP）"。
2. **"好的开始是成功的一半"**：规划阶段的核心是站点目标——目标越明确工作越具体；目标要编辑成文档打印出来，遇到争议先问"这有助于站点目标实现吗？"。教学价值：给学生的期末项目立"目标先行"的规矩。
3. **分工与协作**：素养目标2——通过团队角色体会分工合作，"社会性是人最基本的属性"。4 人小团队角色可兼任：项目经理/系统分析员/测试、程序员/系统分析员、设计师/测试、网站编辑/测试。
4. **测试贯穿全程**："唯一解决方案是不断测试"；测试是周期性工作，越早发现问题代价越小（教材原话）。
5. **"实践是检验真理的唯一标准"**：素养目标3——用"游戏天地"完整案例让学生体会项目实践的复杂性与可操作性。

## 教学目标（教材原文摘要）

- 知识：了解规划、设计、开发、发布、维护的开发流程及各阶段考虑因素；了解团队构成；了解策划书主要内容。
- 技能：运用开发流程做项目；组织/加入团队并明确职责；撰写网站策划书；掌握网站测试方法；能独立或协作完成完整网站。
- 素养：理解 SOP 概念；体会分工协作；体会项目实践的复杂性和可操作性。

## 知识点

### KP-10.1 网站开发流程（五阶段）
| 阶段 | 关键活动 | 教材要点 |
|---|---|---|
| 1.规划 | 定站点目标（成文！）→ 定目标用户（不可能让所有人满意）→ 定整体风格（布局/颜色/字体/图像/标志；**简约是主流，KISS 原则：Keep It Simple and Stupid**）→ 评估技术因素（带宽：图像与多媒体数量大小决定下载速度；浏览器：至少兼容 Chrome/Safari/IE-Edge/Firefox 主流；分辨率：移动设备差异大→**响应式是基本要求**）→ 规划信息架构（内容组织要符合普通人思维习惯，参考同类网站） | 行17172–17260 |
| 2.设计 | 导航设计（按内容逻辑关系而非随意链接，详见8.4）、页面版式设计（先定内容→纸上或PS画布局→程序员定技术方案；要点：以网站目标为准绳、保持一致性、注意可读性、简单明了），主页设计（回答四问：这是什么网站/有什么/能做什么/为什么用它不用别的；常见组成部分：标志与使命、导航系统、搜索、主题图片、实时内容、广告、快捷方式、注册登录） | 行17262–17336 |
| 3.开发 | 按效果图用 HTML/CSS/JS 实施；**先做模板网页，认可后形成系统技术方案再全面铺开**；测试不能忽视、贯穿全程 | 行17338–17364 |
| 4.发布 | 向 ISP 申请网页空间 → 用 FTP 软件或 Dreamweaver 上传 | 行17366–17374 |
| 5.维护 | 不断更新内容吸引和留住访问者，根据反馈完善，回到规划阶段循环 | 行17376–17386 |

练习题考点：内容结构属规划阶段（题4 A）；测试通常不考虑"开发工具"（题5 D）——考虑操作系统/浏览器/分辨率；填空7 答案"维护"。

### KP-10.2 网站开发团队
六角色（小团队）：**项目经理**（计划制定与监督、例会、与客户和高层沟通、对偏差负责——练习题1 答案：✗，主持计划制定的是项目经理不是系统分析员）、**系统分析员**（通晓技术、评估开发人员能力、制订项目计划、解答技术问题、审查代码）、**程序员**（HTML/CSS/JS + Bootstrap/jQuery 等前端技术，把设计付诸实施）、**设计师**（美工/UI/UX，效果图创作、图像资源管理优化、多媒体加工）、**网站编辑**（文字内容编辑整合，使内容符合网页"扫描而非阅读"的展示特征；教材强调：传统团队易忽略，但"内容"是网站最重要的元素）、**测试人员**（实时测试并反馈）。填空10 答案：测试人员。
说明：角色与人员可多对多；典型 4 人分工见行17460–17468。

### KP-10.3 网站策划书（10 项内容）
1 前期调研分析（市场状况、竞争者、客户群、自身条件）/ 2 建站目的及功能定位 / 3 技术解决方案（自建服务器或虚拟主机、操作系统、现成方案或自开发、安全措施、后端与数据库、前端技术与工具）/ 4 内容规划 / 5 网页设计（CI 规范、目标群体、改版计划）/ 6 网站维护 / 7 网站测试（服务器稳定性安全性、程序与数据库功能、兼容性、链接有效性、内容正确性、下载速度）/ 8 发布与推广（公关广告、发布细节、搜索引擎登记与优化、友情链接与社群推广）/ 9 开发日程表 / 10 费用明细。
练习题考点：题3 ✓（策划书含竞争对手信息）；题6 C（"网站代码实现"不属于策划书内容）。
**教学用法**：期末项目要求每组交付一份简化版策划书（可裁剪为 5 项：调研、目的与功能、内容规划、设计、日程）。

### KP-10.4 案例：游戏天地网站的规划
- 背景：引第51次《中国互联网络发展状况统计报告》（2023年3月发布）——截至2022年12月我国网络游戏用户5.22亿，占网民48.9%。**注意时效**：授课时用最新一期报告数据替换（CNNIC 每年两期，**待人工核对**最新数据）。
- 目标：对游戏玩家——理解游戏是艺术形式与文化载体；对非玩家——消除误解。
- 风格："简约活泼、图文并茂"（简约风降低认知复杂度 + 活泼体现游戏灵动 + 读图时代图像优先）。
- 技术因素：带宽不成障碍但图像仍要压缩；跨 Windows/iOS/Android/Linux 平台与主流浏览器；做成响应式。
- 信息架构（5 栏目）：游戏研究（电子游戏发展史/游戏的定义/大师说游戏/现代游戏研究→下设游戏设计/叙事/游戏化）、仙剑奇侠传（世界观+仙剑1–7共10页）、古剑奇谭（古剑1/2/3/Online）、王者荣耀（新手指南/英雄介绍/英雄攻略/成瘾机制，英雄介绍攻略按射手法师战士坦克刺客辅助分页）、隐形守护者（背景故事/角色介绍）。选游戏三原则：影响力大、类别有代表性、背景文化积极正面并以中华文化为中心。

### KP-10.5 案例：导航与页面设计
- 主导航：顶部，左侧站点标志（点击回首页）+5 栏目水平排列；悬停加下画线、当前栏目加粗；**屏幕宽度低于768px 时折叠为按钮**（移动版）。
- 面包屑：主导航之下，二级页面为"首页 > 栏目名"，首页可点、栏目名加粗；**二级导航直接集成在面包屑中**（按钮形式、"|"分隔、当前页加粗）。
- 三级导航：面包屑之下用"分页链接"（pagination）居中。
- 页面设计：主页 = 导航条 + **轮播图**（对应5栏目主题图）+ footer；二级页 = 导航条+面包屑 + 多个**卡片**（子栏目主题图+文本）+ footer；三级页 = 导航条+面包屑+二级导航 + 子导航条 + 两栏内容 + footer。
- 设计工具提示：可用 Visio/AxureRP 画线框图（wireframe），便于留存修改与远程交流；手绘亦可快速交流。

### KP-10.6 案例：实现流程与代码架构
实现流程（DW 为工具）：建站点文件夹并放入 bootstrap 文件夹（Bootstrap+jQuery 文件）→ DW 新建站点"游戏天地" → 根目录建 html/css/js 文件夹和 index.html → 制作 index.html（用 9.5.1 的 emmet/代码片段提效；CSS 入 css/、JS 入 js/、图片处理后入 images/）→ html/ 目录建子页面 → **完成后用 9.3.3 的方法全站检查超链接**。

代码架构要点：
- **公共部分复用**：所有页面公用头部/导航条/面包屑/页脚——教材建议把这些做成 DW"代码片段"。
- **分层样式表**：`main.css` 放全站公共 CSS（整体架构与风格），`pages.css` 放具体页面特定样式。这是贯穿全书的"分层样式表"模式收官。
- **路径陷阱**：index.html 在根目录用 `./`，html/ 下的页面用 `../`——教材明确提醒"所有../都要替换为./"。这是学生项目最常见的死链/裂图根源。
- 头部引用顺序：bootstrap.min.css → jquery-3.4.1.slim.min.js → bootstrap.bundle.min.js → bootstrap.min.js → main.css（→ pages.css）。

典型页面实现（均可作课堂拆解素材）：
1. **主页**：Bootstrap navbar（`navbar-expand-md bg-dark navbar-dark` + navbar-toggler 折叠按钮 + `collapse navbar-collapse`）+ Carousel 轮播（`carousel-indicators` 指示器 + 5 个 `carousel-item` + prev/next 控制）+ footer；页内 `<style>` 设轮播图 `width:100%;height:auto` 响应式。
2. **二级页**：row + `col-md-6` 栅格两列卡片（card/card-img-top/card-body/card-title/card-text/`btn btn-outline-secondary`）；面包屑"首页 > 古剑奇谭"。
3. **三级页**：pagination 分页导航（`page-item disabled/current`）+ 左列 accordion 折叠栏（`data-toggle="collapse"`、`data-parent="#accordion"`、默认 `collapse show` 展开第一项）+ 右列响应式图片（`img-fluid`）+ **自写 JS 交互**：技能图标悬停切换——CSS 默认 `#skill2-4{display:none}`、`#skill1{display:block}`，高亮图与普通图配对，`onmouseover="showHide(n)"` 触发 pages.js 的 showHide()：循环 4 次先全部复位（块 none、普通图 inline、高亮图 none），再显示当前块与高亮图。
   - 教学亮点：showHide 是第7章 DOM `getElementById().style.display` 的实战；CSS 里的默认状态设计（"先全部隐藏再单独显示"）是经典模式，值得专门讲解。
   - 导航条 CSS 技巧：给所有 `nav a` 加与背景同色的透明下画线，悬停时只改颜色——**避免悬停时盒子尺寸跳动**（教材注释明确说明此动机，是极好的工程细节教学点）。
   - 按钮按下效果：`#second-nav a{position:relative}` + `:hover{left:1px;top:1px}` 偏移模拟。

### 时效与技术更新提示
- 案例用 **Bootstrap 4.4.1 + jQuery 3.4.1 slim**。Bootstrap 5 的变化：不再需要 jQuery、`data-toggle`→`data-bs-toggle`、`data-target`→`data-bs-target`、`data-slide`→`data-bs-slide`、`.ml/mr-*`→`.ms/me-*`；同时引入两个 JS 文件（bundle 已含 Popper，再引 bootstrap.min.js 属冗余——**教材代码此处冗余，可作点评素材**）。若用 Bootstrap 5 重做本项目，属拓展挑战任务。
- 文件名用中文（如"古剑奇谭-首页.html"）：教材如此，但现代实践建议文件名用英文小写+连字符，避免 URL 编码与服务器兼容问题——课堂可讨论。
- `<big>` 标签在 HTML5 中已废弃（教材三级页用了 `<strong><big>`），现代替代：CSS `font-size`。可作业内点评点。
- IE 浏览器已于 2022 年 6 月退役，教材"兼容 Internet Explorer"的要求可更新为"兼容 Edge 及主流浏览器"。

## 反模式

- ❌ 跳过规划直接写代码 → 返工。✅ 先写站点目标文档与信息架构图。
- ❌ 开发后期才测试 → 问题堆积。✅ 测试贯穿全程、周期性进行。
- ❌ 全面铺开做页面后再统一风格 → 风格不一致。✅ 先做模板网页，认可后再铺开。
- ❌ 各页面复制粘贴公共代码 → 改一处要改十处。✅ 公共代码做成代码片段/抽公共 CSS（main.css）。
- ❌ index.html 与子页面混用 `../` 和 `./` → 资源 404。✅ 按页面所在层级核对相对路径。
- ❌ 主页堆砌所有内容 → 认知超载。✅ KISS 原则，主页只回答"四问"。
- ❌ 团队只有分工没有沟通机制 → 接口对不上。✅ 例会制度 + 策划书成文 + 项目经理监督。
