# 模块 6：选题策划与脚本创作

> 知识来源：【专业补充】为主。教材第 8 章的节目结构实践（片头动画 → 开场白 → 标题 → 专题内容 → 片尾字幕）与"先策划、后制作"的工程顺序可作为结构依据；选题学、脚本写作方法为教学补充内容，已在下文逐项标注。

## 一、教学目标

**知识目标**
1. 掌握音频节目选题的来源、评估维度与可行性论证方法【补充】。
2. 掌握节目脚本的结构规范：片头、开场、主体段落、转场、片尾（结构依据见 2.2）。
3. 了解音频节目主要形态及其脚本差异【补充】。

**能力目标**
1. 能撰写一份要素完整的选题策划书（选题、受众、形式、结构、素材计划、进度）。
2. 能写出可直接进入录音阶段的分段脚本（含解说词、采访问题、音效/音乐标注）。

**素养目标**：建立受众意识与"声音叙事"思维——先想清楚听众如何"听"，再决定怎么"做"。

## 二、理论知识

### 2.1 选题来源与评估【专业补充】
- **选题来源**：个人经历与兴趣、校园/社区热点、人物故事、知识科普、文化艺术。
- **评估四问**：①值得讲吗（价值）？②有人听吗（受众）？③采得到吗（素材可得性）？④做得完吗（时间与技术可行性）？
- **可行性论证**：素材是否可触达（采访对象、场地）、是否需要经费、是否有法律/伦理风险（未成年人、隐私）。

### 2.2 节目结构（教材第 8 章结构的教学化提炼）
教材"计算机专题讲座"项目的成品结构为：**片头动画 → 开场白 → 标题（配切换音效）→ 专题内容一段接一段 → 片尾与字幕**。该结构对纯音频节目完全成立：
- **片头**（5–10 秒）：节目名称 + 标志性音乐（音频节目的"听觉 logo"）【补充】
- **开场白**：本期导语，说清"这期讲什么、为什么值得听"【补充】
- **标题/转场**：段落之间的切换音效或过渡语（教材用切换音效 + 标题画面，音频节目中对应为转场音与章节口播）
- **主体**：2–4 个段落，每段一个子主题
- **片尾**：总结 + 制作名单 + 下期预告

### 2.3 主要节目形态与脚本差异【专业补充】
| 形态 | 脚本核心 | 结构特点 |
|---|---|---|
| 播客对谈 | 提纲 + 话题卡 | 弱脚本、强现场；仍需开场与收尾模板 |
| 声音纪录片/人物专题 | 完整解说词 + 采访清单 + 音效设计 | 强脚本；先写解说词骨架，再安排采访填补 |
| 广播剧 | 文学剧本 + 音效提示表 | 场景化写作，"声音能听懂的画面" |
| 知识讲解 | 逐字稿 | 口语化改写是关键 |
| 音乐节目 | 歌单 + 串联词 | 版权合规优先 |

### 2.4 解说词写作要点【补充】
口语化（念着顺耳）、短句优先、数字与专有名词读法标注、为音效和留白写"气口"；脚本三栏式排版：**时间码 | 声音内容（解说/采访/音效/音乐） | 备注**。

## 三、操作步骤：从选题到脚本的四周流程

1. **第 1 周：选题 brainstorm**——每人提 3 个选题，小组投票聚合。
2. **第 2 周：可行性论证**——按 2.1 四问调研，写策划书初稿。
3. **第 3 周：结构搭建**——按教材结构定片头/段落/片尾，画"声音结构草图"（每段什么声音、几分钟）。
4. **第 4 周：脚本定稿**——写解说词与采访提纲，标注全部音效与音乐需求（含授权计划）；组内通读试听（朗读 + 计时），修改后提交评审。

## 四、案例分析

**案例：把一份平庸策划改到可执行（教学化案例）**
- 初稿选题："大学生心理健康"——范围过大、无具体人物与场景。
- 评估：素材可得性低（受访者难约）、结构无法落地。
- 修改后："寝室夜谈：三个考研人的失眠与自救"——具体人物（同寝三人可触达）、具体场景（寝室实地录音）、天然段落（三人各一段 + 夜谈穿插）。结构按教材式五段设计：片头（环境声 + 节目名）→ 开场白 → 三人故事（每段转场用熄灯音效）→ 夜谈合段 → 片尾。
- 教学要点：选题的"小"不是格局小，而是可执行、可触摸、可共情【补充】。

## 五、课堂练习

1. 选题四问快评：教师给出 3 个学生选题，全班用评估四问打分并排序。
2. 脚本改写：把一段书面语文字（200 字）改写成口语化解说词，同桌互读检验"顺耳度"。
3. 结构草图：为自己节目画 1 页声音结构草图，标出每段时长与主要声音元素。

## 六、课后任务（里程碑 1）

小组提交《选题策划书 + 完整脚本》：
- 策划书：选题阐述、受众分析、形态选择、可行性论证、进度甘特图、素材与授权清单
- 脚本：三栏式完整脚本（含全部音效/音乐标注与授权来源）

## 七、评价标准

| 项目 | 权重 | 要点 |
|---|---|---|
| 选题价值与可行性 | 25% | 四问论证充分，素材可落实 |
| 结构完整性 | 25% | 片头/段落/转场/片尾齐全（对标教材结构） |
| 脚本可执行性 | 30% | 能直接指导录音，音效标注齐全，口语化达标 |
| 创新性与受众意识 | 20% | 有独特角度，清楚为谁而做 |
