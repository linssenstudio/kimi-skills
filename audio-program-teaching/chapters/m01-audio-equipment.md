# 模块 1：音频设备与录音系统搭建

> 知识来源：教材第 1 章 1.1 节"常用音频编辑设备的功能及特点"。设备型号与存储介质介绍为 2009 年内容，使用时以"原理 + 现代等价设备"方式讲授。

## 一、教学目标

**知识目标**
1. 说出音频系统中三类设备（采集/输入、编辑处理、输出/放音）的划分及各自代表设备。
2. 解释电容、驻极体电容、动圈麦克风的工作原理差异与适用场景。
3. 解释单方向、双方向、全方向指向性的拾音特性与典型用途。
4. 描述音频工作站的三大组成：计算机硬件系统、音频处理软件、音频接口。

**能力目标**
1. 能根据节目形态与预算列出设备清单并说明选型理由。
2. 能正确连接麦克风—音频接口—计算机—监听设备，组建一套可用的录音系统。

**素养目标**：树立"设备服务于创作"的观念，理解没有昂贵设备也能做出合格节目（教材案例多使用常规设备完成）。

## 二、理论知识

### 2.1 音频设备的三大类别（教材第 1 章）
- **音频采集设备（输入设备）**：麦克风、无线麦克风接收系统、录音机、调音台输入端等。
- **音频编辑设备**：调音台、音频工作站（计算机 + 音频编辑软件 + 音频接口）。
- **音频输出设备（放音设备）**：音箱（有源/无源）、耳机。

### 2.2 麦克风的类型与原理（教材 1.1）
| 类型 | 原理 | 特点 | 典型用途 |
|---|---|---|---|
| 电容麦克风 | 声波使声膜振动，电容容量变化转成电信号 | 灵敏度高、指向性强，需配放大器/调音台 | 专业音乐录音、高品质对白录音 |
| 驻极体电容麦克风 | 驻极体振动膜与金属极板构成电容，声波引起电场变化产生交变电压 | 体积小、结构简单、电声性能好 | 手机、数码相机、摄录一体机拾音，无线麦克风主流 |
| 动圈麦克风 | 声膜带动音圈在永磁体磁场中振动产生感应电动势 | 坚固耐用、无需供电 | 卡拉 OK、会议报告 |
| 佩戴式（领夹）麦克风 | 微型驻极体电容 | 体积极小，解放双手 | 运动场景、外出采访 |

### 2.3 指向性（教材 1.1）
- **单方向**：只拾取所指方向，其他方向不敏感 → 高质量音乐录制、专业对白、舞台主持。
- **双方向**：拾取方向及反方向 → 二重奏录制、**面对面访谈节目**（采访教学直接相关）。
- **全方向**：各方向均匀拾取 → 新闻采访、圆桌讨论。

### 2.4 无线麦克风系统（教材 1.1）
UHF 无线麦克风内置调制发射器，经天线发射，由调谐接收机解调出声音信号；佩戴式无线麦需外接发射机（可挂腰间或装在摄像机上），非常适合室外录音与新闻采访。

### 2.5 录音与处理设备（教材 1.1）
- **麦克风放大器**：麦克风输出电压微弱，专业录音需先放大再做均衡、补偿处理。
- **录音机**：模拟录音机（盒式磁带、开盘式磁带）与数字录音机（DAT、硬盘、光盘、存储卡/便携录音机）。教材指出：数字录音是当代声音采集存储的主流。
- **调音台（Audio Mixing Console）**：多路输入输出，对每路信号单独处理（放大、音调调节、空间定位、混合调整）；分模拟调音台与数字调音台。数字调音台内置效果器、混响器、均衡器、压缩/限制器，信噪比和动态范围高。
- **音频工作站**：以计算机为核心，由计算机硬件 + 音频编辑软件 + 音频接口三部分构成。音频接口决定工作站功能属性：
  - 声卡基础接口：MIC In（麦克风，粉色）、Line In（线性输入，接录音机/CD 机等辅助音源）、SPK（音箱）。
  - 专业数字接口：S/PDIF（光纤/同轴，避免模拟连接的噪声衰减）、ADAT（光纤 8 轨数字音频）、IEEE1394/火线接口器。
- **监听设备**：有源音箱内置功放、方便但功率受限；无源音箱需外接功放、适用范围宽。耳机是剪辑监听的必备工具。

### 2.6 现代等价设备映射【专业补充】
| 教材设备（2009） | 现代教学等价物 |
|---|---|
| 声卡 + 麦克风 | USB 麦克风（内置声卡）或 XLR 麦克风 + USB 音频接口 |
| DAT/磁带录音机 | 便携数字录音笔、手机 + 录音 App |
| 火线音频接口 | USB-C 音频接口（Focusrite Scarlett、Audient 等入门系列） |
| 调音台 | 小型 USB 调音台或 DAW 软件混音台 |
| 光盘录音机 | 计算机 + DAW 直接导出 |

## 三、操作步骤：组建一套学生录音系统

1. **确定需求**：节目形态（单人播客/双人访谈/外景采访）决定麦克风数量与类型。
2. **选型**：优先保证"安静的录音环境 + 近距离拾音"，再考虑设备档次。
3. **连接**：麦克风 →（音频接口/XLR 线）→ 计算机 → 打开 DAW → 选择输入通道。
4. **设置采样参数**：44.1 kHz / 16 bit 以上（教材中 CD 音质标准，见模块 3）。
5. **试录与监听**：戴耳机回放，检查噪声、音量、左右声道。
6. **形成设备清单与连接图**：作为课后任务提交。

## 四、案例分析（教材案例教学化重构）

**案例：面对面访谈节目的拾音方案（教材 1.1 双方向指向性应用）**
- 场景：两人在桌前面对面访谈。
- 教材方案：使用双方向麦克风，可同时清晰拾取两人声音，且抑制侧面环境噪声。
- 现代方案【补充】：两支单方向电容麦各对一人；或一支双方向麦置于两人中间；室外则用两支无线领夹麦 + 手机/录音笔备份。
- 教学讨论：为什么不用全方向麦？（侧面噪声、混响被一起拾取，见模块 3 遮蔽效应。）

## 五、课堂练习

1. 设备辨识：给出 8 张设备图（麦克风四种、调音台、声卡、音箱、录音笔），说出名称、类别（采集/编辑/输出）与一项用途。
2. 连线题：为三种节目形态（单人深夜播客、双人访谈、外景随机采访）匹配指向性与设备组合。
3. 实操：在教师指导下完成一次 USB 麦克风接计算机并录 30 秒试音。

## 六、课后任务（对接 PBL 项目）

小组提交《录音系统方案》：设备清单（含租赁/借用渠道与预算）、系统连接图、录音环境选择与降噪措施说明，供项目录音阶段使用。

## 七、评价标准

| 项目 | 权重 | 要点 |
|---|---|---|
| 选型匹配度 | 30% | 设备与节目形态、预算匹配，理由引用教材原理 |
| 连接图正确性 | 25% | 信号流向正确、接口名称规范 |
| 环境方案 | 25% | 考虑了噪声、混响、电源与备份 |
| 文档规范 | 20% | 清单完整、图文清晰 |
