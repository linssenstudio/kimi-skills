# 模块 4：录音技术与声音采集实践

> 知识来源：教材第 3 章 3.4 节"常用的声音采集方法"（直接采集、转换采集）及 3.3 节采集流程；软件操作部分教材以 Windows XP 录音机为例，教学时映射到现代免费软件 Audacity（操作逻辑一致：检查属性 → 设置格式 → 录音 → 保存）。

## 一、教学目标

**知识目标**
1. 说出声音采集的两种方式：直接采集与转换采集，及各自适用场景。
2. 描述直接采集系统的四大组成：麦克风、声卡（音频接口）、编辑计算机（音频工作站）、采集软件。
3. 记住数字录音的标准参数设置流程（教材以 44.1 kHz/16 bit/立体声 CD 音质为例）。

**能力目标**
1. 能独立完成一次完整录音：连接设备 → 检查录音属性 → 设置格式 → 录音 → 保存命名。
2. 能录制三类项目素材：人声解说（干声）、环境音效、素材转录。

**素养目标**：养成录音前检查、录音中监听、录音后即刻备份的职业习惯。

## 二、理论知识

### 2.1 声音采集的两种方式（教材 3.4）
- **直接采集**：把个人语音或环境音效等声源通过麦克风直接采集到存储设备中。应用最广，节目配音及音响效果多采用此方式。典型系统（教材图 3-18）：**麦克风 + 声卡 + 编辑计算机 + 声音采集软件**；麦克风接声卡的 MIC 输入口（粉色、标 MIC 字样）。教材同时指出：录音笔、MP3 播放器等数码设备也可直接采集，更简便灵活，但音质与格式受设备限制——**正式项目素材优先用工作站录制**。
- **转换采集**：把现有声音文件从一种格式/设备转换为另一种，常用于背景音乐的引入或原始录音的调用（详见模块 7 格式转换）。

### 2.2 采集的物理过程（教材 3.3）
声源 → 话筒（声波 → 模拟电信号）→ 压缩量化（模拟 → 数字电信号）→ 数字文件。模拟音频被采集成数字音频是"连续波形 → 离散数字量"的过程。

### 2.3 录音前的检查与设置（教材 3.4 操作流程提炼）
1. 连接：麦克风插入 MIC 接口，接好耳机。
2. 检查录音属性：确认录音设备可用、麦克风处于选中状态（教材在"录音控制"窗口勾选"麦克风"）。
3. 设置格式：**PCM 44.1 kHz、16 bit、立体声**（教材明确此即为 CD 音质属性，约 172 KB/s）。
4. 试录并监听波形：波形饱满但不顶满；无声段应接近平直。
5. 正式录音：录音中随时观察电平；结束后立即试听。
6. 保存：**源文件存 WAV 无损格式**，命名规范 `节目名_素材类型_序号_日期.wav`（如 `食堂故事_采访_03_1024.wav`）。

### 2.4 录音质量自检清单【专业补充，依据教材原理】
- 电平：峰值 -12 ~ -6 dB，不触 0 dB（教材：电平过高波形失真）。
- 噪声：安静段落底噪是否可闻（教材背景噪声概念；模块 3 遮蔽效应）。
- 完整：开头结尾各留 5 秒环境声/静音，便于后期剪辑留白。
- 备份：现场素材当天双份保存（计算机 + 移动硬盘/云盘）。

## 三、操作步骤：用 Audacity 完成一次标准录音（映射教材流程）

1. 打开 Audacity，编辑 → 首选项 → 音频设置：采样率 44100 Hz。
2. 选择录音设备（USB 麦克风/音频接口）与录音声道（人声可用单声道，音乐用立体声）。
3. 点击"录制"按钮试录 20 秒，停止后看波形与电平表。
4. 调整麦克风距离（15–30 cm，略偏轴防喷麦）或接口增益，使峰值在 -12 ~ -6 dB。
5. 正式录音；出错不要停，停顿 3 秒后重说该句（后期剪除）。
6. 文件 → 导出 → 导出为 WAV（16 bit PCM）存档。
7. 填写素材记录单：内容、时长、地点、设备、参数、文件名。

## 四、案例分析

**案例：教学片配音素材采集（教材 3.4 直接采集 + 第 8 章"CPU配音/光驱配音/显示器配音"项目情境）**
- 情境：为"计算机硬件讲座"系列节目录制三段解说配音。
- 教材做法：分段录制三个 WAV 文件（CPU 配音、光驱配音、显示器配音），每段单独命名保存，供后期与画面对位剪辑。
- 教学讨论：为什么不一口气录完再剪？（分段录制降低返工成本：某段口误只需重录该段；教材第 8 章正是利用分文件实现音画分轨调整。）
- 迁移到纯音频节目：按脚本分场景/分段落录音，每段一条文件，是广播节目与播客的标准工作方式【补充】。

## 五、课堂练习

1. 参数设置实操：3 分钟内在 DAW 中完成 44.1 kHz/16 bit 设置并说明每步理由。
2. 距离实验：分别以 10 cm / 30 cm / 60 cm 录同一段话，对比近讲效应、 room 噪声与混响差异，记录结论。
3. 环境音采集：在教室、走廊、操场各录 30 秒环境声，标注可用性（哪段可作背景、哪段噪声太大不可用）。

## 六、课后任务（对接 PBL 项目）

按本组脚本录制至少以下素材并提交素材库：
- 人声解说/主持干声（覆盖脚本全部内容）
- 采访素材（至少 1 段，若节目形态含采访）
- 环境音效或背景音乐素材（注明来源与授权情况）
- 素材记录单与命名规范的执行截图
