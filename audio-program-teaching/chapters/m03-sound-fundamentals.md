# 模块 3：声音科学与数字音频基础

> 知识来源：教材第 3 章 3.1–3.3 节（声音信号的基本特点、声音信号的数字处理过程、声音采集的基本流程）。这是全书理论密度最高的部分，是学生理解"为什么这样录音/导出"的根基。

## 一、教学目标

**知识目标**
1. 说出声音的三要素（声调、声强、音色）及其物理决定因素。
2. 解释取样、量化、编码三个数字化步骤，陈述奈奎斯特取样规则。
3. 记住常用指标：人耳可听范围 20 Hz–20 kHz；CD 音质 44.1 kHz / 16 bit；动态范围公式 6N+1.8 dB。
4. 解释遮蔽效应及其在音频压缩与录音实践中的意义。

**能力目标**
1. 能读懂音频文件的属性参数（采样率、位深、声道、码率）并判断适用场景。
2. 能用动态范围、量化噪声概念诊断"录音音量过小/过大"问题。

**素养目标**：养成"先看参数再操作"的专业习惯，杜绝" defaults 直接用 "的糊涂操作。

## 二、理论知识

### 2.1 声音的种类（教材 3.1.2）
- **纯音**：单一频率正弦波（音叉）。
- **复合音**：两个以上纯音的合成，最低频率成分称**基波/基频**。
- **谐波（倍频）**：与基本音成整数倍频率的成分。
- **单音**：一个基本音与其整数倍谐波组成（钢琴单键）。
- **噪音**：无规律非周期性声音；信号处理中把对象声音之外的一切声音称为**背景噪声**。

### 2.2 声音的三要素（教材 3.1.3）
| 要素 | 由什么决定 | 关键数据 |
|---|---|---|
| 声调（音调） | 频率高低 | 人耳可感知约 20 Hz–20 kHz |
| 声强 | 振幅大小，用 dB（SPL）表示 | 0 dB SPL = 2×10⁻⁵ Pa（1 kHz 最小可听值）；会话平均约 60 dB |
| 音色 | 谐波成分（频谱、波形、声压的综合差异） | 不同乐器同曲同响度仍可分辨的原因 |

教材强调：声音的强度与感觉大小并不一致——人耳对 4 kHz 左右最敏感（等感度曲线），这解释了"响度相同的两个声音听感不同"。

### 2.3 听感与遮蔽效应（教材 3.1.4）
- **最小可听极限**：曲线以下听不到；频率高于 15 kHz 时最低可听声强较高，高频噪声对听觉妨碍相对小。
- **遮蔽效应**：干扰噪声使最小可听曲线上升的现象，上升量称遮蔽量。教材给出三条规律：
  1. 只要有声音存在就形成遮蔽，**频率越靠近遮蔽越大**；
  2. **低音遮蔽高音的效果比高音遮蔽低音大**；
  3. 遮蔽音强度增大，遮蔽量也增大。
- 应用：MP3 等音频压缩正是利用遮蔽效应去掉"听不到"的成分（教材指出"这在音频数字压缩时是可以利用的"）。录音实践推论【补充】：嘈杂环境中人声细节被低频遮蔽，应优先控制低频环境噪声。

### 2.4 模拟 vs 数字（教材 3.1.5–3.1.6）
- 模拟信号：时间轴连续，直观但精度低、易受干扰，且**劣化无法消除**（噪声和失真经多次处理不断累积）。
- 数字信号：时间轴离散、幅度离散（0/1），抗干扰——只要还能区分电平高低或脉冲有无，就能正确识别 0 和 1（限幅消除振幅性干扰）；多次复制/传输后干扰不积累。代价：数码率高、需压缩、需检错纠错。

### 2.5 数字化三步骤（教材 3.2）
1. **取样**：以恒定频率在时间轴上离散取值。奈奎斯特取样规则：**取样频率必须大于信号最高频率的两倍**才能不失真还原，否则产生频谱混叠。音频最高 20 kHz → 取样率须大于 40 kHz → 实际采用 **44.1 kHz**。
2. **量化**：把取样值归类到有限个电平（4 bit = 16 级；16 bit = 65,536 级）。量化位数即 A/D 变换的分辨率。实际值与量化值之差产生**量化噪声**——位数越少、量化噪声越大；每秒取样 88,200 次 + 16 bit 量化即可基本消除量化噪声（教材原话要点）。
3. **编码**：量化值转为二进制码，得到 PCM（脉冲编码调制）信号。波形编码三方式：**PCM**（直接模数转换，最多 16 bit 存储，音质最好）、**DPCM**（只传预测值与样本差值，降低编码率）、**ADPCM**（自适应调整量化步长，进一步压缩）。

### 2.6 动态范围（教材 3.2）
- 定义：噪声电平与最大不失真信号电平之间的范围。
- **公式：动态范围（dB）= 6 × N + 1.8**（N 为量化比特数）。
- 数据：14 bit → 86 dB；16 bit → 98 dB；CD 实际 97.8 dB（理想值 100 dB）；模拟磁带约 50 dB。
- 推论【补充】：24 bit（约 144 dB）成为现代录音/混音标准，但发布仍常用 16 bit。

### 2.7 声音采集基本流程（教材 3.3）
声源 → 话筒（声波转模拟电信号）→ 音频采集设备（模拟转数字：取样量化 + 压缩）→ 存储介质 → 音频编辑工作站 → 播放/输出设备。波形编码（PCM/DPCM/ADPCM）在存入计算机时常用于压缩数据量。

## 三、操作步骤：读懂并设置一次录音参数

1. 打开 DAW 的音频设置，查看当前采样率与位深。
2. 将参数设为 **44.1 kHz（或 48 kHz）/ 24 bit**（教材 CD 标准为 44.1 kHz/16 bit；现代录音建议 24 bit 留足动态余量【补充】）。
3. 录制 30 秒朗读，观察电平表：峰值控制在 -12 dB 至 -6 dB 之间，不顶到 0 dB（防削波失真，对应教材"信号电平过高波形会失真"）。
4. 导出两个版本：WAV（44.1 kHz/16 bit）与 MP3（192 kbps），比较文件大小与听感。
5. 填写《参数记录单》：采样率、位深、声道、格式、文件大小。

## 四、案例分析

**案例："为什么我录的音一调大音量就全是嘶嘶声？"（教材 3.1.5 + 3.2 原理诊断）**
- 症状：录音电平太小，后期加大音量后噪声明显。
- 教材原理：模拟阶段信号过弱则信噪比恶化（噪声相对变大）；量化阶段信号过小则接近量化噪声底。录音时电平应"大而不破"——利用满动态范围（教材：16 bit 动态范围 98 dB），把信号电平提到接近最大不失真电平但不过载。
- 正确做法：录音时峰值 -12~-6 dB；宁可录音偏大一点，也不要录完再大幅提音量（教材 6.3.1 也提醒：提高音量时杂音也随之提高）。

## 五、课堂练习

1. 计算题：16 bit 量化的动态范围是多少？24 bit 呢？（用 6N+1.8）
2. 判断题：取样率 22.05 kHz 能否完整记录 15 kHz 的泛音？（奈奎斯特：不能，会产生混叠）
3. 听音训练：播放同一段音乐的不同码率 MP3（128/192/320 kbps），听辨差异并解释（遮蔽效应）。
4. 实操：按"三、操作步骤"完成参数设置与双格式导出。
