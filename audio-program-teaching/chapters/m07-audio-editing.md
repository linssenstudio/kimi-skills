# 模块 7：音频剪辑与后期制作

> 知识来源：教材第 6 章"声音素材的编辑处理"（6.1 文件格式、6.2 格式转换、6.3 Windows 录音机与 GoldWave 编辑操作）；教材所用软件为 2001–2009 年版本，教学时将操作逻辑映射到现代 DAW（Audacity / Adobe Audition / 剪映专业版），方法原理完全沿用教材。

## 一、教学目标

**知识目标**
1. 说出 WAV、MP3、WMA、MIDI、CD-DA 等常见音频格式的特点、压缩率与适用场景（教材 6.1）。
2. 理解格式转换的原则：编辑用无损 WAV，发布用压缩 MP3（教材 6.2 思想）。
3. 掌握音频编辑四大基本操作：选段、剪切/删除、混合（混音）、音量/变速/特效处理（教材 6.3）。

**能力目标**
1. 能用 DAW 完成素材整理：分割、排序、去口误、去停顿。
2. 能完成段落级精修：选段精确到秒、淡入淡出处理、基本降噪。
3. 能完成一次格式转换并说明参数选择理由。

**素养目标**：建立"无损存档、压缩发布"的文件管理纪律与"少即是多"的特效使用观（教材提醒回音过重影响清晰度）。

## 二、理论知识

### 2.1 常见音频文件格式（教材 6.1）
| 格式 | 特点（教材要点） | 教学定位 |
|---|---|---|
| WAV | Microsoft/IBM 标准，44.1 kHz/16 bit，支持多种压缩算法；未压缩、音质好、数据量大 | **编辑与存档格式** |
| MP3 | MPEG Audio Layer-3，有损压缩，压缩率 10:1–20:1；同长度文件约为 WAV 的 1/10，音质仅次于 CD/WAV | **发布与传输格式** |
| RA/RM/RAM | RealNetworks 流式音频，随网络带宽自适应音质 | 历史知识，已式微【补充说明】 |
| AIF/AIFF、AU | Apple 与 UNIX 平台常见格式 | 跨平台交换时注意 |
| WMA | 微软流式压缩，压缩率约 1:18，支持 DRM | 历史知识 |
| VQF | YAMAHA 专用高压缩格式，需专用播放器 | 历史知识（教材批评其"不常见"） |
| CD-DA | 音频光盘格式，约 74 分钟，无压缩高保真 | 抓轨转 WAV/MP3 的来源（教材 6.2.1） |
| MD | SONY MiniDisc，ATRAC 压缩、可编辑 | 历史知识 |
| MIDI | 存"乐谱"指令而非声音，数据量极小，音质取决于声卡/合成器 | 配乐创作入门了解 |

教材要点总结：格式选择由**最终用途**决定——保音质用 WAV，省空间用 MP3，网络实时传输用流式。

### 2.2 格式转换原则（教材 6.2）
- CD → MP3：抓轨软件读取音轨 → 设输出路径 → 设压缩比/位率 → 转换（教材 6.2.1 流程）。
- MIDI → WAV、MP3 → WAV：转换器选择源文件 → 设输出格式与路径 → 开始转换（教材 6.2.2/6.2.3 流程）。
- 教学映射【补充】：现代用 Audacity/Audition"导出"功能或 FFmpeg；核心问题不变——**目标格式的位率与采样率怎么定**：发布 MP3 建议 192 kbps（音乐）/ 128 kbps（语音）以上、44.1 kHz。

### 2.3 编辑操作原理（教材 6.3）
- **插入声音**：在指定位置插入另一段声音，其后内容自动后移——用于拼接与编排。
- **混合声音（混音）**：在现有声音上叠加新声音，原长度不变——教材举例"配乐解说"：前面是解说，同时有音乐作背景，这是最常用的编辑方式。混音时若背景音乐长于解说，文件总长增加；短于则总长不变。
- **删除**：删除游标前或后的内容——用于去掉开头过长静音、剪掉废段。
- **音量调整**：教材警告"提高音量的同时，杂音也将随之相应提高"——**增益不能代替好的录音**（呼应模块 3 动态范围）。
- **变速**：加速/减速改变时长，每次操作变化一倍幅度。
- **特效**：回音每执行一次增加一级，**过重会直接影响声音清晰度**；反转（倒放）可产生特殊效果。
- **GoldWave 工作法（教材 6.3.2）**：试听定位 → 两条选择控制线精确选段（可放大电平显示微调）→ 删除/剪切 → 淡入淡出（淡入处理片段开头、淡出处理结尾，消除生硬进出）→ 另存为选格式。要点提示（教材原文精神）：无论主显示窗放大多少倍，副显示窗始终显示整个文件——**用副窗看全局，用主窗做精细**。

### 2.4 剪辑的核心心法（教材贯穿性方法）
1. 先试听，后下刀（教材所有案例都是先播放定位再编辑）。
2. 选段宁多勿少，先粗剪后精剪。
3. 段落进出用淡入淡出软化（教材 GoldWave 案例的标准收尾）。
4. 每一步保留原文件，编辑在副本上进行（呼应教材"项目文件与输出分离"）。

## 三、操作步骤：从原始素材到初剪版（现代 DAW 流程，对应教材流程）

1. **工程准备**：建"素材/工程/成品"三分目录；把原始 WAV 复制进素材目录（原盘不动）。
2. **素材粗筛**：每条素材听一遍，重命名加评级（A 必用/B 可用/C 弃用）。
3. **按脚本排时间线**：把 A 级素材依脚本顺序拖入轨道。
4. **粗剪**：剪除废句、长停顿、口误（保留 0.3–0.5 秒呼吸间隙）。
5. **精修**：逐段听，做选段微调、音量匹配（段与段响度一致）。
6. **降噪**：仅对持续底噪做轻度降噪，宁留一点噪声不留"水下音"【补充】。
7. **段落进出**：每段开头 0.2–0.5 秒淡入、结尾淡出（教材淡入淡出法）。
8. **存工程 + 导出初剪版 WAV**，交里程碑 3 评审。

## 四、案例分析

**案例：用 GoldWave 做手机铃声（教材 6.3.2 案例教学化）**
- 任务：从歌曲《童话》中剪出高潮段做铃声。
- 教材流程：试听定位高潮 → 暂停后拖选择控制线到进度线 → 反复试听精确定位 → 放大电平显示微调 → 删除不需要的前后段 → 对开头淡入、结尾淡出 → 另存为 MP3。
- 迁移练习【补充】：在 Audacity 中完成"从一段 4 分钟采访里剪出 40 秒金句"——同样的工作法：试听定位、选段、删除、淡入淡出、导出。
- 教学要点：剪辑不是"删掉错的"，而是"留下对的"——选段能力比删除能力重要。

## 五、课堂练习

1. 格式侦探：给出 5 个真实音频文件属性截图，判断用途并给出转换建议（引用教材格式知识）。
2. 剪辑计时赛：3 分钟内从一段录音中剪除一处口误并做淡出，导出提交。
3. 混音体验：按教材"配乐解说"方式，把 60 秒解说与一段背景音乐混合，音乐音量调到能衬人声中不喧宾夺主（-15 dB 左右起调）【补充参数】。

## 六、课后任务（里程碑 3：节目初剪版）

提交初剪版 WAV + 剪辑说明（剪了什么、删了什么、哪些素材被弃用及原因），供下次课评审。
