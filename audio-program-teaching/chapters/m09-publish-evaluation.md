# 模块 9：节目发布、展示与作品评价

> 知识来源：【专业补充】为主。教材第 2 章"节目播出系统"（播出是制作流程的最后一环）与第 8 章"输出成品"构成发布环节的知识骨架；平台运营、版权授权、展评组织为教学补充内容，已逐项标注。

## 一、教学目标

**知识目标**
1. 理解"播出系统"在制作链条中的位置（教材第 2 章：录制 → 编辑 → 播出）。
2. 了解音频节目的发布渠道与各自的上传规范【补充】。
3. 掌握音频作品评价的四个维度与量规使用方法。

**能力目标**
1. 能完成一次规范发布：成品文件、封面、节目简介、shownotes、标签齐全。
2. 能使用量规对他组作品进行有依据的评价，并能依据评价修改自己的作品。

**素养目标**：建立公开发布的版权责任意识与接受公众评价的心理准备。

## 二、理论知识

### 2.1 播出系统——教材中的最后一环（教材 2.3）
教材把节目播出系统分为：收录系统、数据中心、播控系统——核心思想是**成品必须经过规范的最后一站才能到达受众**。对音频节目而言，"播出系统"就是发布平台与发布动作本身：文件合格（格式、响度、命名）→ 元数据完整（标题、简介、封面）→ 平台分发。

### 2.2 发布渠道与规范【专业补充】
| 渠道 | 适合形态 | 上传要点 |
|---|---|---|
| 校园广播/校园网 | 全部 | 按台里技术规范交 WAV/MP3 |
| 播客平台（小宇宙、Apple Podcasts 等） | 播客、专题 | MP3 44.1 kHz、封面 3000×3000、shownotes 带时间戳 |
| 音频社区（喜马拉雅、网易云音乐等） | 有声书、广播剧、音乐节目 | 注意平台版权审核 |
| 课程平台 | 全部 | 按课程要求命名与提交 |

发布检查单【补充】：文件可正常播放 / 响度统一 / 封面清晰 / 简介无错别字 / 音乐素材已列鸣谢 / 采访对象已确认发布范围。

### 2.3 版权与授权【专业补充】
- 音乐素材：优先使用免版税音乐（ royalty-free 库）或取得授权；教材 6.1 提到 WMA 支持 DRM——DRM 即数字版权管理，说明数字音频从格式层面就有版权保护机制。
- 采访素材：以模块 5 的知情同意为发布前提。
- 引用素材：注明出处，控制引用比例，不歪曲原意。

### 2.4 作品评价方法
- 四维评价：**内容策划 / 声音技术 / 剪辑节奏 / 混音包装**（详细量规见模块 0 总表）。
- 评价方式：教师评分（40%）+ 小组互评（30%）+ 班级听评会现场投票（30%）。
- 评价不是终点：要求每组依据收到的评价提交一条修改记录（改了什么、为什么）。

## 三、操作步骤：发布与展评流程

1. 发布前自检：对照发布检查单逐项打勾。
2. 上传发布：按所选渠道完成上传，记录链接。
3. 课堂听评会：每组播放作品精华 3 分钟 + 创作陈述 2 分钟（选题由来、最大的困难、最满意的设计）。
4. 互评：各组用量规打分并写一条"最有价值的优点 + 最有价值的建议"。
5. 修改与归档：按反馈完成至少一处修改，提交最终版与反思报告。

## 四、案例分析

**案例：一次"差一点不能播"的发布（教学化案例）**
- 情境：小组上传前夜发现背景音乐来自未授权的商业歌曲，平台审核将不予通过且有侵权风险。
- 处置【补充】：改用免版税音乐库替换；片尾增加"音乐鸣谢"清单；采访段落逐条与被访者确认发布授权。
- 教学要点：发布环节是版权合规的"最后一道闸"——教材的播出系统思想：最后一站不容省略，规范的成品才配得上播出。

## 五、课堂练习

1. 元数据写作：给自己节目写 100 字节目简介 + 5 个标签，同桌互评"是否会点开听"。
2. 量规校准：全班听同一段样例节目，独立打分后公布分差并讨论量规描述的"可区分性"。

## 六、课后任务（最终成果）

1. 完成真实发布（或课程平台模拟发布），提交链接与截图。
2. 提交个人反思报告（800–1500 字）：复盘全流程，至少包含"一个最成功的决策 + 一个最痛的教训 + 若重做会改的一件事"。
3. 各组提交最终版文件与修改记录。

## 七、评价标准（作品终评，占总评 40%）

| 维度 | 权重 | 评分要点 |
|---|---|---|
| 内容策划 | 25% | 选题价值、结构完整、脚本执行度 |
| 声音技术 | 25% | 录音质量、参数达标、无明显技术瑕疵 |
| 剪辑与节奏 | 20% | 剪辑干净、转场自然、时长控制合理 |
| 混音与包装 | 15% | 比例恰当、片头片尾完整、响度统一 |
| 发布规范 | 15% | 元数据完整、版权合规、按时发布 |

## 八、PPT 教学要点

1. 封面：作品抵达听众的最后一公里
2. 制作三系统收尾图：录制→编辑→播出（教材 2.3 播出系统结构）
3. 发布渠道对比表【补充】
4. 发布检查单页【补充】
5. 版权三问：音乐授权了吗？采访同意了吗？引用标注了吗？【补充】
6. 四维评价量规总表（模块 0）
7. 听评会流程与礼仪【补充】
