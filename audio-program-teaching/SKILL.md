# 音频节目创作与教学 Skill

**知识来源**：《音视频编辑与电视节目制作》，韩雪涛主编，电子工业出版社，2009（约 192 页，8 章，扫描版全书经 OCR 提取）
**使用对象**：大学本科师生（教材原为高职教材，本 Skill 已按本科教学深度重构）
**教学模式**：项目制教学（PBL）——以学生独立完成一档 8–15 分钟音频节目为最终成果
**生成日期**：2026-10-10

## 核心知识框架（教材精华）

### 音频节目制作全流程（教材工作流程的音频化）
**选题策划 → 脚本创作 → 声音采集（直接采集/转换采集）→ 剪辑后期 → 混音合成 → 输出发布**
教材按实际工作流程划分章节（采集→编辑→合成输出），所有教学模块与之一一对应，学生始终清楚"这一步在整档节目中的位置"。

### 数字音频核心指标（教材第 3 章，必须记牢）
- 人耳可听范围：**20 Hz – 20 kHz**；最敏感频率约 4 kHz
- 奈奎斯特取样规则：取样频率 > 信号最高频率 ×2 → 音频采用 **44.1 kHz**
- 量化：16 bit = 65,536 级；**动态范围 = 6N + 1.8 (dB)** → 16 bit ≈ 98 dB，CD 实际 97.8 dB
- 波形编码三方式：PCM（音质最好）/ DPCM / ADPCM
- 标准录音参数（教材）：**PCM 44.1 kHz / 16 bit / 立体声 = CD 音质**
- 电平纪律：电平过高 → 波形失真；电平过低 → 淹没于噪声；提音量 = 同时提噪声

### 关键方法（教材第 6、8 章）
- 编辑四操作：**插入 / 混音（配乐解说最常用）/ 删除 / 效果（音量·变速·回音·反转）**
- GoldWave 工作法：**试听定位 → 选段（主窗精调 + 副窗看全局）→ 删除 → 淡入淡出 → 另存**
- 对位工作法（教材 8.1）：**播放找切合点 → 偏移处切分 → 拖动对齐 → 删除多余停顿 → 复听**
- 节目合成结构（教材 8.2）：**片头 → 开场白 → 标题/转场 → 主体段落链接 → 片尾**
- 文件纪律：**项目文件（工程）与成品文件分离保存**；编辑用 WAV 无损，发布用 MP3 压缩

### 麦克风选型速记（教材第 1 章）
- 电容麦：灵敏、指向强 → 专业音乐/对白录音；动圈麦：耐用 → 会议/卡拉 OK
- 单方向 → 专业对白/主持；**双方向 → 面对面访谈**；全方向 → 新闻采访
- 佩戴式无线麦 + 发射机 → 室外采访/运动场景
