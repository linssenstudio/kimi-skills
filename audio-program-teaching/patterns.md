# 操作技巧与流程库（Patterns）

> 全部流程来自教材的提炼与教学化重构；标注【补充】者为教材未涵盖的教学必需流程。

## P1 录音系统搭建流程（教材 1.1 + 3.4）
**何时用**：项目启动阶段、搭建录音环境。
**怎么做**：确定需求（节目形态 → 麦克风数量/类型）→ 选型（优先保证安静环境 + 近距离拾音）→ 连接（麦克风 → 音频接口 → 计算机 → 耳机）→ 设置参数（44.1 kHz / 16 bit 以上）→ 试录监听 → 形成设备清单与连接图。
**注意**：教材强调采集设备（接口/声卡）在很大程度上决定系统能力；不必追求高端，先求可用与安静。

## P2 标准录音流程（教材 3.4）
**何时用**：所有人声、环境音采集。
**怎么做**：连接设备 → 检查录音属性（确认麦克风被选中）→ 设置格式（PCM 44.1 kHz/16 bit/立体声，CD 音质）→ 试录 20 秒看电平 → 正式录音（峰值 -12 ~ -6 dB【补充区间】）→ 即时试听 → 保存 WAV。
**要点**：出错不停机，停顿 3 秒后重说该句，后期剪除【补充】。

## P3 分段录音法（教材第 8 章项目情境）
**何时用**：解说、配音类素材。
**怎么做**：按脚本分段/分场景录制，每段一条独立文件（教材案例：CPU 配音、光驱配音、显示器配音三个文件）。
**为什么**：降低返工成本；便于后期逐段对位与替换；某段口误只重录该段。

## P4 采访录音全流程（教材 1.1 拾音方案 +【补充】流程）
**何时用**：人物访谈、外景采访。
**怎么做**：场勘（听噪声、选座位）→ 架设（双方向麦置中间 / 两支单方向麦各 20–30 cm / 无线领夹）→ 测试（双方各说 30 秒并回放）→ 开场记录（日期、对象、授权）→ 正式采访（开放式问题、留白、追问）→ 收尾补充 → 当天双备份。
**教材依据**：双方向麦适于面对面访谈；佩戴式无线麦 + 发射机适于室外；全方向麦适于多人递话筒场合。

## P5 音频剪辑五步法（教材 6.3.2 GoldWave 工作法）
**何时用**：所有剪段、精修操作。
**怎么做**：① 试听定位（播放找点）→ ② 选段（两条控制线；主显示窗放大微调、副显示窗始终看全局——教材要点）→ ③ 删除/剪切 → ④ 进出处理（开头淡入、结尾淡出，消除生硬感）→ ⑤ 另存导出（选格式与音质）。
**心法**：先试听，后下刀；选段宁多勿少，先粗剪后精剪。

## P6 对位工作法（教材 8.1）
**何时用**：两条轨（解说与现场声/采访/音乐节点）的时间对齐。
**怎么做**：整体播放找到切合点 → 拖动素材整体对位 → 发现偏移：在偏移处切一刀（教材剃刀分割）→ 后段拖动对齐 → 停顿过长则剪掉多余段（教材 Clear 删除）→ 复听逐点修正。
**教材案例**：显示器配音与讲座视频的对位——整体拖到 0:00:03 开始；"扫描信号产生电路"配音提前 → 切分后拖后；"行输出级电路"停顿过长 → 剪除多余段。

## P7 配乐解说混音法（教材 6.3.1 混合声音）
**何时用**：人声 + 背景音乐的合成。
**怎么做**：打开人声文件 → 游标移到需要配乐处 → 混合音乐文件（混音，长度不变；音乐长于解说则总长增加）→ 调整音乐比例（比人声低约 15–20 dB【补充起点】）→ 段落衔接处交叉淡化【补充】。
**教材警告**：提高音量的同时杂音也随之提高——增益不能代替好的录音。

## P8 节目合成三段式（教材 8.2）
**何时用**：把片头、段落、片尾组装成完整节目。
**怎么做**：① 全部素材导入项目 → ② 按结构顺序拖入时间线：片头 → 开场白 → 标题/章节口播（配切换音效）→ 主体段落 → 片尾 → ③ 转场处理（音频用交叉淡化/转场音效；教材视频用过渡特效并精确调持续时间与方向）→ ④ 逐段复听。
**教材细节**：标题停留 4 秒（音频对应章节口播 3–5 秒）；切换音效与标题同刻进入。

## P9 文件管理纪律（教材第 8 章 +【补充】）
**何时用**：全程。
**怎么做**：三分目录（素材/工程/成品）；原始素材只读存档、编辑在副本上进行；工程文件（Save）与成品文件（Export）分离；命名规范 `节目名_素材类型_序号_日期`；成品双格式（WAV 存档 + MP3 发布）。

## P10 格式转换流程（教材 6.2）
**何时用**：素材格式不统一、需要发布版本。
**怎么做**：选择源文件 → 选输出格式 → 设输出路径 → 设参数（采样率/位率/声道）→ 转换 → 检查输出文件。
**原则**：编辑与存档用 WAV 无损；网络发布用 MP3（192 kbps 起步【补充】）；转换软件性能影响质量（教材强调）。

## P11 噪声控制现场法（教材 3.1.4 遮蔽效应的应用）
**何时用**：现场录音选址。
**怎么做**：避开低频声源（空调、马路——教材"低音遮蔽高音"会吞掉人声清晰度）；优先小空间 + 吸音面（窗帘、地毯）；戴上监听耳机闭眼听 10 秒，细节听不清的位置不录【补充操作】。

## P12 发布前检查流程（教材 2.3 播出思想 +【补充】清单）
**何时用**：成品上传前。
**怎么做**：文件可正常播放 → 响度统一 → 片头片尾齐全 → 封面/标题/简介/标签完整 → 音乐素材已列鸣谢且授权 → 采访对象已确认发布范围 → 备份最终版。
