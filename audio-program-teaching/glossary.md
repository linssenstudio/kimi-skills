# 术语表（Glossary）

> 来源标注：教材章节或【补充】。按拼音排序。

**ADAT 接口** — 数字光纤接口，允许 8 轨数字音频信号通过光纤传输，用于数字调音台等与计算机的高品质连接（教材 1.1）。

**ADPCM** — 自适应差分脉冲编码调制，对 DPCM 的改进，通过调整量化步长进一步压缩音频数据（教材 3.3）。

**背景噪声（黑噪音）** — 以某些声音为对象时，该声音以外的一切声音（教材 3.1.2）。

**白色噪声（白噪音）** — 包含所有频率分量、幅度恒定的声音（教材 3.1.2）。

**采样（取样）** — 数字化第一步，以恒定频率在时间轴上对模拟信号离散取值（教材 3.2）。

**采样率** — 每秒取样次数；音频标准 44.1 kHz，源自奈奎斯特规则（教材 3.2）。

**编辑控制器** — 控制摄录像机、录像机、编辑机实现节目编辑控制的设备（教材 1.2）。

**插入编辑** — 在已录好的节目带中等长插入新内容替换旧内容的线性编辑方式（教材 2.2.2）。

**插入声音** — 在指定位置插入另一段声音、其后内容自动后移的编辑操作（教材 6.3.1）。

**颤音/混音（混合声音）** — 在现有声音上叠加新声音、原长度不变的编辑操作；教材举例"配乐解说"为最常用形式（教材 6.3.1）。

**纯音** — 单一频率正弦波，如音叉声（教材 3.1.2）。

**磁带录音机** — 模拟录制设备，盒式/开盘式磁带存储，动态范围约 50 dB（教材 1.1、3.2）。

**DAT** — Digital Audio Tape，专业数字录音格式，采样率 48/44.1/32 kHz（教材 1.1）。

**动态范围** — 噪声电平与最大不失真信号电平之间的范围；公式 6N+1.8 dB（N 为量化位数），16 bit ≈ 98 dB（教材 3.2）。

**动圈麦克风** — 声膜带动音圈在磁场中振动产生感应电动势的麦克风，坚固耐用，用于卡拉 OK、会议（教材 1.1）。

**电容麦克风** — 声波使电容容量变化转为电信号的麦克风，灵敏度高、指向性强，需配放大器，用于专业录音（教材 1.1）。

**调音台（Audio Mixing Console）** — 多路输入输出、可对每路单独处理（放大、音调、空间定位、混合）的设备，分模拟与数字两类（教材 1.1）。

**定量/量化** — 数字化第二步，把取样值归类到有限个二进制电平；位数越少量化噪声越大（教材 3.2）。

**短句优先** — 解说词写作原则：口语化短句念着顺耳【补充】。

**段落链接** — 把编辑好的节目片断按顺序组合成完整节目的合成环节（教材 8.2）。

**对线/对位** — 音频与视频（或两条音轨）在时间上对齐的剪辑工作（教材 8.1）。

**多普勒、回声、混响、降噪** — GoldWave 内置音频处理特效举例（教材 6.3.2）。

**耳闻-logo** — 节目片头的标志性音乐，建立听觉识别【补充】。

**非线性编辑系统（NLE）** — 以多媒体计算机为编辑核心、以硬盘为存储媒体的数字化后期制作系统；可跳跃搜索、任意增删（教材 2.2.5）。

**复合音** — 包含两个以上纯音的声音，最低频率成分为基波（教材 3.1.2）。

**高保真** — 高采样频率实时录音，追求接近原声的音质（教材 1.1）。

**GoldWave** — 集声音编辑、播放、录制、转换为一体的音频工具，教材指定教学软件（教材 6.3.2）。

**干扰抑制（遮蔽）** — 见"遮蔽效应"。

**还有呢？（追问技巧）** — 采访中用沉默等待被访者补充的提问策略【补充】。

**混音** — 多路声音信号合并为一路并平衡各轨比例的艺术与技术过程（教材 1.1、6.3.1）。

**基波/基频** — 复合音中的最低频率成分（教材 3.1.2）。

**交叉淡化** — 两段声音在重叠区渐变的音频转场方式，对应视频转场特效的音频等价物【补充】。

**节目播出系统** — 节目制作三系统之一，负责存储、管理与播出（教材 2.3）。

**节目录制系统** — 节目制作三系统之一，负责素材摄取，分演播室与外景（教材 2.1）。

**节目编辑系统** — 节目制作三系统之一，负责剪辑、合成、特技（教材 2.2）。

**近讲效应** — 麦克风贴近声源时低频增强的现象，录音距离实验的观察点【补充】。

**开场白** — 节目开头介绍本期内容的段落（教材 8.2 结构）。

**可读性（可听性）** — 解说词念着顺耳、听着明白的写作标准【补充】。

**量化噪声** — 实际信号电平与量化电平之差产生的噪声，位数越多噪声越低（教材 3.2）。

**录音机** — 音频录制保存设备，分模拟（磁带）与数字（DAT/硬盘/光盘/存储卡）两类（教材 1.1）。

**录音控制** — 操作系统中管理录音输入设备与音量的面板（教材 3.4）。

**领夹（佩戴式）麦克风** — 微型驻极体电容麦克风，运动与外出采访场景使用（教材 1.1）。

**麦克风放大器** — 将麦克风微弱电压信号放大并做均衡补偿处理的设备（教材 1.1）。

**MIDI** — 数字乐器接口国际标准，存"乐谱"指令而非声音本身，数据量极小（教材 6.1）。

**MP3** — MPEG Audio Layer-3，有损压缩格式，压缩率 10:1–20:1，同长度文件约为 WAV 的 1/10（教材 6.1）。

**奈奎斯特取样规则** — 取样频率必须大于信号最高频率两倍才能不失真还原（教材 3.2）。

**逆变/反转（倒放）** — 将声音文件倒置播放的特效（教材 6.3.1）。

**PCM** — 脉冲编码调制，直接对声音模数转换的编码方式，音质最好（教材 3.3）。

**PBL** — 项目制学习，以学生完成真实项目为核心的教学模式【补充】。

**片头** — 节目标志性开场（音频节目中为标志音乐 + 节目名口播）（教材 8.2 结构 +【补充】）。

**频谱** — 声音各频率成分的分布图（教材 3.1）。

**平衡（电平）** — 各轨声音响度的协调关系（教材 6.3 混音思想）。

**干扰效应** — 见"遮蔽效应"。

**切换音效** — 节目段落切换时配合标题/转场的音效（教材 8.2）。

**声卡** — 计算机最基本的音频接口，提供 MIC In、Line In、SPK 等接口（教材 1.1）。

**声强** — 声音大小，用 dB（SPL）表示；0 dB SPL = 2×10⁻⁵ Pa（教材 3.1.3）。

**声压** — 声波使大气压变化的幅度，单位 Pa（教材 3.1.3）。

**声像** — 声音在立体声场中的位置感【补充】。

**声源** — 产生声音的物体振动（教材 3.3）。

**声调（音调）** — 声音三要素之一，由频率决定（教材 3.1.3）。

**失步** — 磁带编辑中 CTL 信号不连续导致的跟踪伺服错乱、图像紊乱（教材 2.2.1）。

**实时传输** — 随网络带宽自适应音质的流式播放方式（教材 6.1）。

**声纹/音色** — 声音三要素之一，由谐波成分决定，区分同音高同响度的不同声音（教材 3.1.3）。

**双方向麦克风** — 拾取正前正后两个方向、抑制侧面的麦克风，适于面对面访谈（教材 1.1）。

**数字录音机** — 以 DAT、存储卡、硬盘、光盘为介质的录音设备（教材 1.1）。

**数字信号** — 时间轴与幅度均离散的信号，0/1 表示，抗干扰、不积累劣化（教材 3.1.6）。

**数字调音台** — 内置效果器/均衡器/压缩器等数字处理器的调音台，信噪比与动态范围高（教材 1.1）。

**数字音频工作站（DAW）** — 以计算机为核心的录音编辑系统：硬件 + 音频软件 + 音频接口（教材 1.1 +【补充】术语）。

**衰减（淡出）** — 片段结尾音量渐小的处理，消除生硬结束（教材 6.3.2）。

** fade in/淡入** — 片段开头音量渐大的处理（教材 6.3.2）。

**听感（等感度曲线）** — 人耳对不同频率感觉灵敏度不同的特性，4 kHz 最敏感（教材 3.1.3–3.1.4）。

**听觉 logo** — 见"耳闻-logo"【补充】。

**同步** — 多轨素材在时间上一致播放的状态（教材 8.1）。

**WAV** — Microsoft/IBM 标准音频格式，44.1 kHz/16 bit，未压缩音质好、数据量大，为编辑存档格式（教材 6.1）。

**误码** — 数字信号在记录、传输中的数据丢失或错误，需检错纠错机制消除影响（教材 3.1.6）。

**静默段** — 录音开头结尾预留的静音区，便于后期剪辑留白【补充】。

**XLR 接口** — 专业音频设备常用的平衡卡侬接口【补充】。

**显示窗/电平表** — 显示声音波形振幅与时间关系的窗口（教材 3.4、6.3.2）。

**谐波（倍频）** — 与基本音成整数倍频率的声音成分（教材 3.1.2）。

**线性编辑** — 在磁带上按顺序剪辑的节目编辑方式，修改困难（教材 2.2）。

**信噪比** — 信号与噪声的强度比；模拟信号经处理会劣化，数字信号不积累（教材 3.1.5–3.1.6）。

**项目文件** — 保存编辑状态的工程文件（教材 Save，如 .ppj），区别于导出成品（教材 8.1）。

**胸麦** — 见"领夹麦克风"。

**音讯** — 见"音频"。

**有源音箱** — 内置功率放大器的音箱，接音源即可播放，功率受限（教材 1.1）。

**音频编辑软件** — 决定音频工作站性质的软件层，如 Protools、Cakewalk、GoldWave（教材 1.1、6.3）。

**音频工作站** — 进行声音录制、编辑、处理及输出的综合性设备，以计算机为核心（教材 1.1）。

**音频接口** — 为计算机提供音频输入输出能力的设备，其特性决定工作站功能属性（教材 1.1）。

**遮蔽效应** — 干扰噪声使最小可听曲线上升的现象；频率越近遮蔽越大、低音遮蔽高音更强（教材 3.1.4）。

**音量调整** — 提高或降低声音电平的操作；提高音量的同时杂音也随之提高（教材 6.3.1）。

**音质** — 声音的保真品质，受采样率、位深、压缩率等影响（教材第 3、6 章）。

**音速调节（变速）** — 加速/减速改变声音时长的效果操作（教材 6.3.1）。

**降噪** — 降低持续背景噪声的处理【补充】。教材 GoldWave 特效列表含"降噪"（教材 6.3.2）。

**预卷** — 线性编辑中编辑点回倒磁带使两机同步的过程，专业机 3–10 秒（教材 2.2.1）。

**原始素材** — 未经编辑的采集文件，应无损存档（教材第 8 章流程）。

**匀加速（加速）** — 每次执行声音加快一倍的效果（教材 6.3.1）。

**载体/介质** — 声音存储载体：磁带、硬盘、光盘、存储卡（教材 1.1）。

**暂停键** — 录音机/编辑机控制键；编辑中用于精确设点（教材 2.2）。

**侦听器（耳机）** — 剪辑监听必备，有源/无源音箱用于放音输出（教材 1.1）。

**帧** — 视频时间单位；音频编辑中对应时间码（教材 8.1）。

**组合编辑** — 把素材带节目一段接一段组合录到新磁带、要求磁迹衔接良好的线性编辑方式（教材 2.2.1）。

**最终混音** — 节目全部元素合成后的成品混音【补充】。

**驻极体电容麦克风** — 极薄塑料膜驻极体构成电容的麦克风，体积小、应用最广（手机、无线麦）（教材 1.1）。

**专利/版权（DRM）** — 数字版权管理，WMA 等格式可加入防复制保护（教材 6.1）。

**转换采集** — 把现有声音文件转换为其他格式存储的采集方式，常用于背景音乐引入（教材 3.4）。

**转场** — 节目段落之间的过渡处理：音频中用交叉淡化或转场音效（教材 8.2 +【补充】）。

**免版税音乐（Royalty-free）** — 付费一次或免费即可在约定范围内使用的授权音乐，学生节目背景音乐首选【补充】。

**总线（Bus）** — 调音台中合并多路信号的通路【补充】。

**最大可听极限** — 人耳能承受的声强上限（教材 3.1.3）。

**最大不失真电平** — 信号不失真的最高电平，超过则波形削波失真（教材 3.2）。

**最小可听极限** — 人耳能听到的最小声强，随频率变化的曲线（教材 3.1.4）。

**作品评价量规（Rubric）** — 分维度、分等级的评分标准表（模块 0 总表）【补充】。

**行为式提问** — 用"能举个例子吗""当时发生了什么"引导被访者讲具体事例而非观点的采访技巧【补充】。
