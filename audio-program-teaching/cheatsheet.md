# 速查与决策表（Cheatsheet）

> 决策依据主要来自教材；标注【补充】者为现代教学参数建议。

## 1. 录音参数决策

| 场景 | 采样率 | 位深 | 格式 | 依据 |
|---|---|---|---|---|
| 课程练习录音 | 44.1 kHz | 16 bit | WAV | 教材 CD 音质标准 |
| 正式项目录音 | 44.1/48 kHz | 24 bit | WAV | 留动态余量【补充】 |
| 存档母版 | 44.1 kHz | 16–24 bit | WAV | 教材：WAV 音质好、宜存档 |
| 网络发布 | 44.1 kHz | — | MP3 ≥192 kbps | 教材：MP3 约为 WAV 1/10 |
| 语音类节目发布 | 44.1 kHz | — | MP3 ≥128 kbps | 【补充】 |

电平红线：峰值 **-12 ~ -6 dB**，绝不超过 0 dB（教材：过高失真、过低淹没于噪声）。

## 2. 麦克风指向性决策（教材 1.1）

| 场景 | 指向性 | 理由 |
|---|---|---|
| 单人解说/配音 | 单方向 | 抑制环境噪声 |
| 面对面双人访谈 | 双方向 | 教材：适于面对面访谈节目 |
| 新闻采访（递话筒） | 全方向 | 教材：多用于新闻采访 |
| 外景走动/运动 | 佩戴式无线 | 教材：室外录音常用 |
| 会议/卡拉 OK | 动圈（单方向为主） | 教材：耐用、通用 |

## 3. 格式选择决策（教材 6.1 +【补充】）

- 要编辑、要存档 → **WAV**（未压缩、全软件支持）。
- 要发布、要传输 → **MP3**（10:1–20:1 压缩，音质接近 CD）。
- 要极小数据量、只要"乐谱" → MIDI（但音质取决于合成器）。
- 收到 RA/RM/WMA/VQF 等老旧格式 → 先转 WAV/MP3 再编辑。

## 4. 剪辑决策规则

- **先听再剪，不看不剪**——教材所有案例均先播放定位。
- **进出必淡**——段落开头淡入、结尾淡出，消除生硬感（教材 GoldWave 案例标准收尾）。
- **音量不够 → 回录，不硬拉**——提音量 = 提噪声（教材 6.3.1 警告）。
- **回音适度**——每加一级回音增色，过重直接损害清晰度（教材原话要点）。
- **先粗剪后精剪**——先删大块废段，再微调选段（教材工作法）。

## 5. 混音决策规则

- 人声是主角：背景音乐比人声低 **15–20 dB** 起步，以"听得到不费力"为准【补充】。
- 配乐解说进出的标准做法：音乐随解说开始淡入、随解说结束淡出（教材混合声音法）。
- 全片各段落响度保持一致（教材音量匹配思想）。
- 两个素材对位错位：在偏移点切一刀、拖动对齐、删多余停顿（教材 8.1 工作法）。

## 6. 节目结构速查（教材 8.2 结构的音频化）

片头（5–10 秒，标志音乐+节目名）→ 开场白（本期导语）→ 段落一（章节口播+转场音效）→ 段落二 → … → 片尾（总结+鸣谢+预告）。
标题/章节口播控制在 **3–5 秒**（对应教材标题显示 4 秒）。

## 7. 常见故障速诊

| 症状 | 教材原理 | 处置 |
|---|---|---|
| 调大音量后嘶嘶声明显 | 录音电平过低、信噪比差（3.1.5/3.2） | 重录：峰值提至 -12~-6 dB |
| 声音发闷、不清晰 | 低频环境声遮蔽高频（3.1.4 低音遮蔽高音） | 换环境；避开空调/马路 |
| 0 dB 处波形削平 | 电平过高失真（3.2） | 降增益重录；已削波无法完全修复 |
| 剪口处"咔"声 | 进出未做淡变（6.3.2） | 加 0.2–0.5 秒淡入淡出 |
| 背景音乐盖住人声 | 混音比例失衡（6.3.1） | 音乐降至人声下 15–20 dB |
| 文件太大传不动 | WAV 未压缩（6.1） | 转 MP3（192 kbps） |

## 8. 里程碑检查点（PBL 项目）

1. 选题策划书 + 脚本评审通过（模块 6）
2. 原始素材库齐（干声+采访+音效，模块 4/5）
3. 初剪版 WAV（模块 7）
4. 成品双格式 + 混音说明（模块 8）
5. 发布链接 + 反思报告（模块 9）
