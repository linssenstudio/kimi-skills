# 认知偏差清单与检查方法

第 6 步使用。作用对象有两个：**被审查对象背后的推理**（作者/决策者怎么想的）和**审查请求本身**（用户怎么问的）。多数审查只需要检查与本对象最相关的 3–5 种，不要全表背诵。

## 目录

1. 清单（偏差名 / 表现 / 检查问句）
2. 用户请求中的偏差信号
3. 检查方法

## 1. 清单

### 证据处理类
| 偏差 | 表现 | 检查问句 |
|------|------|----------|
| 确认偏误 | 只找支持证据，回避反例；方案论证通篇是"为什么行"，没有"什么情况下不行" | 对象里最强的反对证据是什么？作者回应了吗？ |
| 可得性偏误 | 用最容易想起的案例做判断（刚看到新闻就觉得风险大） | 这个判断基于数据统计，还是基于"我听说过"？ |
| 幸存者偏差 | 只研究成功案例得出结论 | 失败样本在哪？失败者和成功者起点真的相同吗？ |
| 选择性抽样 | 挑对自己有利的时间段/人群/口径 | 数据区间和口径是谁选的？换一个口径结论还成立吗？ |

### 判断锚定类
| 偏差 | 表现 | 检查问句 |
|------|------|----------|
| 锚定效应 | 第一个数字/方案主导全部后续判断 | 这个数字从哪来的？先独立估算一遍再比较。 |
| 沉没成本 | 已投入成为继续的理由 | "如果不是已经投了这么多，我现在还会开始吗？" |
| 损失厌恶误判 | 为避免确定的损失接受更大的不确定损失 | 止损的代价真的大于继续的期望损失吗？ |
| 承诺升级 | 公开承诺后拒绝承认方向错误 | 最近有没有新证据？它改变了结论吗，还是没人敢提？ |

### 社会与自我类
| 偏差 | 表现 | 检查问句 |
|------|------|----------|
| 从众/权威偏误 | "大家都这么做"、"某大佬说"作为论据 | 去掉权威署名，这个论证还剩什么？ |
| 乐观偏误（规划谬误） | 时间表与预算系统性乐观（典型：实际 2 倍于估计） | 同类事情通常要多久？最坏时间表是什么？ |
| 自利偏差 | 把成功归能力、失败归环境 | 这个分析里"运气"和"结构"占了多少？ |
| 达克效应信号 | 对复杂领域表现出过度确定 | 作者列出过自己不理解的环节吗？一个都没有=危险信号。 |

### 推理结构类
| 偏差 | 表现 | 检查问句 |
|------|------|----------|
| 虚假二分 | "要么 A 要么 B"，隐藏第三选择 | 还有哪条路没有被列出？ |
| 后此谬误 | 先后发生当因果 | 除了时间先后，机制证据是什么？ |
| 滑坡论证 | 无证据的连锁崩塌预测 | 每一环的传导机制是什么？哪一环最可能断？ |

## 2. 用户请求中的偏差信号

用户的提问方式本身提示了审查重点：

- "我知道没问题，但帮我走个流程" → 确认偏误红旗，反向证据要加量。
- "已经投了 X 了，帮我看看怎么收尾" → 沉没成本介入，检查"继续 vs 止损"是否被平等对待。
- "大家都说这个机会难得" → 从众锚定，检查窗口期证据。
- "帮我看看怎么落地"（未验证方向正确性时） → 用户跳过了 P0 检查，审查应先回应方向再回应落地。

## 3. 检查方法

1. **对照式**：对象中每有一个支持性论据，找对应的一个反例或竞争解释，凑不齐=确认偏误可疑。
2. **基线式**：对象的每个量化断言与公开基线/常识基线对比，偏离大且无解释=可疑。
3. **立场式**：列出谁受益、谁受损、谁没发言权；决策者与受益者高度重合时，自利偏差加权。
4. **时间式**：把对象的关键判断写成可检验的预测，附日期；无法写成预测的判断是观点不是判断。
